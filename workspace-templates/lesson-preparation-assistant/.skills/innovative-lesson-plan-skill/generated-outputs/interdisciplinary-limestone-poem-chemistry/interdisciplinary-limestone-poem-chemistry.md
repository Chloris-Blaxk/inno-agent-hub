## 二、双学科教材分析

### 主学科：

| 维度 | 内容 |
| :--- | :--- |
| 单元定位 | 统编版九年级下册第六单元——古代诗歌鉴赏 |
| 课标要求 | 诵读古代诗词，有意识地在积累、感悟和运用中，提高自己的欣赏品位和审美情趣，理解托物言志的表现手法 |

### 关联学科：

| 维度 | 内容 |
| :--- | :--- |
| 单元定位 | 人教版九年级化学上册第六单元——碳和碳的氧化物 |
| 课标要求 | 认识碳酸钙、氧化钙、氢氧化钙的主要性质及用途，能书写相关的化学反应方程式，理解物质转化的规律 |

### 课标交汇依据

两学科在'物质属性与人文精神关联'层面交汇，化学提供物质变化实证，语文提供情感表达载体，共同服务于'托物言志'手法的深度理解与科学实证精神的培养

## 三、学科关联与融合设计

### 学科关联

| 学科 | 贡献 | 课标依据 |
| :--- | :--- | :--- |
| 语文（主学科） | 提供托物言志的分析框架与情感表达目标，引导学生从物质特性上升到精神品格 | std-chn-g9-poetry-001 |
| 化学（关联学科） | 提供物质变化的实证依据与反应方程式支撑，确保文学解读具有科学事实基础 | std-chem-g9-carbon-001 |

### 融合节点

| 节点 | 描述 | 关联活动 |
| :--- | :--- | :--- |
| node-1 | 【诗 - 化互译】学生以小组为单位，将《石灰吟》四句诗逐句翻译为化学反应方程式和实验现象描述：①千锤万凿出深山→石灰石CaCO₃开采（物理变化）；②烈火焚烧若等闲→CaCO₃高温分解CaO+CO₂↑；③粉骨碎身浑不怕→CaO+H₂O→Ca(OH)₂，生石灰遇水崩解放热；④要留清白在人间→Ca(OH)₂+CO₂→CaCO₃↓+H₂O，碳化生成白色坚硬的CaCO₃层。完成翻译后再将化学语言回译为对诗歌意象的理解。此融合节点要求两个学科知识在同一认知任务中交汇。 | act-2 |

### 共同产出

跨学科鉴赏短文（包含化学方程式支撑的意象分析，体现物与志的逻辑关联）

### 适用边界

化学知识仅限于石灰生产相关的三个核心反应（CaCO₃分解、CaO水化、Ca(OH)₂碳化）的方程式书写与现象描述，不涉及工业制备流程优化、热化学方程式计算、反应速率与平衡讨论。文学分析聚焦于「托物言志」手法的理解与运用，不扩展到诗歌格律分析或于谦全部作品研究。若学生尚未学完碳和碳的氧化物单元，需先用5分钟补充反应链知识卡片。

## 四、学情分析

| 维度 | 分析 |
| :--- | :--- |
| 主学科预备水平 | 学生已具备古诗文诵读基础，能初步感知意象，但对'托物言志'的内在逻辑分析尚浅，常停留在表面修辞理解 |
| 关联学科预备水平 | 学生已完成碳和碳的氧化物单元学习，熟悉石灰石、生石灰、熟石灰的转化关系及方程式，具备基本的实验现象描述能力 |
| 跨学科思维经验 | 缺乏将自然科学原理直接映射到文学意象的系统经验，需引导建立'物性'与'志趣'的对应桥梁，避免学科知识割裂 |

### 教学重点

融合节点'诗 - 化互译'的实施，即如何用化学语言精准解码诗歌意象，并反哺文学理解，实现物性与志趣的深度关联

### 教学难点

融合自然性（避免生硬拼接两个学科任务）与交汇处认知负荷（同时处理符号系统与语义系统），需通过支架降低双重编码难度

## 八、评价量规

| 维度 | 优秀 | 合格 | 待改进 | 证据来源 |
| :--- | :--- | :--- | :--- | :--- |
| 化学知识准确性 | 四个步骤的化学方程式书写完全正确，配平无误，反应条件与现象描述精准对应诗句 | 方程式基本正确，个别配平或条件遗漏，现象描述基本符合事实 | 方程式存在明显错误，或无法将诗句与具体反应步骤对应 | 诗 - 化互译对照表 |
| 物志关联逻辑性 | 能清晰阐述物质特性（如耐高温、变白）与人格品质（如坚韧、清白）的内在逻辑，反事实追问有理有据 | 能指出部分物质特性与品质的联系，但逻辑链条不够完整，反事实分析较浅 | 仅罗列化学知识，未能建立与诗歌主旨的有效关联，或关联牵强 | 鉴赏短文中的论证段落 |
| 跨学科表达质量 | 短文结构完整，科学术语使用规范，文学语言优美，两者融合自然不生硬 | 短文结构基本完整，科学内容正确，但文学表达略显平淡或融合处有割裂感 | 科学内容与文学表达分离，或存在明显的知识性错误影响表达 | 跨学科鉴赏短文终稿 |
