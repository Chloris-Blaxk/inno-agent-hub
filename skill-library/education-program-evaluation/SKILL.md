# Education Program Evaluation

## Goal

Design an evaluation study that judges implementation, effectiveness, value, and improvement opportunities for an educational program/tool/course.

## Inputs

- Program/course/tool/intervention
- Stakeholders
- Evaluation purpose: formative, summative, implementation, impact
- Available data
- Timeline

## Workflow

1. Build logic model: inputs -> activities -> outputs -> outcomes -> impact.
2. Define evaluation questions.
3. Create indicator system.
4. Plan data collection: surveys, interviews, observations, usage logs, outcomes.
5. Select analysis methods.
6. Produce evaluation report and paper outline.

## Tool Calls

Data collection:

```text
Qualtrics, SurveyMonkey, 问卷星, Google Forms, interviews, observation rubrics
```

Analysis:

```text
Excel/Sheets, SPSS, R, Power BI, NVivo/MAXQDA
```

Logic model:

```text
Miro, FigJam, Mermaid, PowerPoint
```

## Output Format

| Evaluation Question | Indicator | Data Source | Analysis | Use |
|---|---|---|---|---|

Include:

- Logic model
- Indicator framework
- Data collection plan
- Analysis plan
- Reporting structure

## Quality Rules

- Separate implementation quality from outcome effectiveness.
- Include stakeholder perspectives.
- Make recommendations traceable to evidence.
