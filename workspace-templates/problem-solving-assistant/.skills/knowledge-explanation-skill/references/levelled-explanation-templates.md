# 分层讲解模板

分层只决定“深浅”，不决定输出格式。实际回复优先遵守 `SKILL.md` 的知识类型判断和单教学动作规则，学生向输出不要机械展示 `contentBlocks` 标题。

## 入门层 `entry`

适用条件：

- 学生前置知识缺失。
- 学生明确要求“从零讲”。
- 错误暴露出基本概念尚未建立。

跨多轮结构要求：

1. 首轮只补一个最关键的前置直觉。
2. 用生活化比喻或直观例子说清“它大概在解决什么问题”。
3. 给一个最小判断题或微例，在这里停住。
4. 学生回应后，再讲准确规则。
5. 需要时再拆一题最简单的典型例题。
6. 易错点和口诀式总结放到后续轮次，不和首轮挤在一起。

语言要求：

- 句子短，术语密度低，像聊天讲题。
- 每一步都说明“为什么能这样做”。
- 同一轮只讲一个稳定方法，不并列多个技巧。
- 可以用一个生活化、带点幽默的核心比喻帮学生抓住概念，但类比后必须回到准确规则。
- 学生向首轮控制在 80-180 字，后续每轮也尽量短。
- 不使用 emoji、对勾叉号或装饰性符号；判断用文字表达。

建议的 `contentBlocks`：

```json
[
  {"title": "先抓直觉", "body": "..."},
  {"title": "一个小判断", "body": "..."}
]
```

## 标准层 `standard`

适用条件：

- 学生能理解基本术语。
- 需要标准定义、规范步骤和典型例题。
- 当前问题主要在方法不稳定，而不是完全不会。

跨多轮结构要求：

1. 首轮给一条核心规则和一个微例。
2. 用一个问题确认学生是否抓住判断标准。
3. 学生回应后，再补通用课程范围内的核心定义或规则；无课标库时不声称来自具体课标条目。
4. 需要例题时，只示范一道典型题的关键步骤。
5. 易错点和检验题根据学生反馈追加，不默认同轮全给。

语言要求：

- 保持规范、可讲授、可复述，但仍然口语化。
- 允许使用学科术语，但不要堆教参式大段表述。
- 优先讲“标准方法”，必要时可补一句替代思路。
- 每个讲解块可加入一句俏皮避坑提醒，帮助学生记住符号、条件或步骤边界。
- 首轮不要同时包含定义、例题、易错点和练习。
- 学生向输出优先 120-260 字，除非用户明确要详细。

建议的 `contentBlocks`：

```json
[
  {"title": "核心规则", "body": "..."},
  {"title": "微例检查", "body": "..."}
]
```

## 拓展层 `advanced`

适用条件：

- 学生已能稳定解决典型题。
- 用户主动要求变式、迁移、对比或更高难度理解。
- 没有检测到前置知识缺口。

跨多轮结构要求：

1. 首轮回顾标准方法的核心不变量。
2. 展示一个变式、迁移或对比点。
3. 学生继续追问时，再对比两种思路并说明适用边界。
4. 易混点和迁移型检验题放在后续轮次。

语言要求：

- 强调迁移、比较和方法选择。
- 不为拔高而拔高，内容仍需留在当前学段边界内。
- 不把竞赛化技巧当成默认标准答案。
- 幽默更克制，优先用于压缩总结或提示方法选择，不打断推理节奏。
- 即使是拓展层，也不要把变式、多解法、易混比较和检验题一次性全部输出。
- 用户要拓展时可以更详细，但每轮仍只展开一个比较点或迁移点。

建议的 `contentBlocks`：

```json
[
  {"title": "先压缩复习标准方法", "body": "..."},
  {"title": "看一个变式或迁移", "body": "..."}
]
```
