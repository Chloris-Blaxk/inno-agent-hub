# Education Action Research Design

## Goal

Turn a teaching problem into an action-research cycle with practical evidence and reflective analysis.

## Inputs

- Teaching problem
- Class/grade/subject context
- Planned intervention or teaching strategy
- Available evidence: student work, observation, interviews, reflections, test scores

## Workflow

1. Diagnose the classroom problem.
2. Define action goal and intervention strategy.
3. Plan cycle: plan -> act -> observe -> reflect.
4. Define evidence sources and evaluation indicators.
5. Draft implementation timeline and ethics.
6. Create paper structure: problem, action, evidence, reflection, improvement.

## Tool Calls

Project tracking:

```text
Notion, Airtable, Excel/Sheets
```

Classroom evidence:

```text
Observation forms, student work rubrics, interviews, reflective journals
```

Analysis:

```text
SPSS/R for simple pre-post data; NVivo/MAXQDA for interview/reflection coding
```

## Output Format

| Cycle | Action | Evidence | Reflection | Next Adjustment |
|---|---|---|---|---|

Include:

- Teaching problem statement
- Action plan
- Evaluation indicators
- Data collection table
- Practice-paper outline

## Quality Rules

- Action research must show change over time, not only describe a lesson.
- Include teacher reflection and evidence of student response.
- Keep claims local unless evidence supports broader claims.
