## 题目

### A 层

q001. 【计算题｜难度 2】计算：2/5 + 1/10 = ?

q002. 【应用题｜难度 2】小华走了 1/4 千米，又走了 1/2 千米。他一共走了多少千米？

q003. 【计算题｜难度 1】计算：2/7 + 3/7 = ?

q004. 【判断题｜难度 2】小红说：3/10 + 7/10 = 10/20 = 1/2。她算得对吗？如果不对，请写出正确答案。

### B 层

q005. 【应用题｜难度 3】一桶油，第一次用去 1/6，第二次用去 1/4。两次一共用去几分之几？还剩几分之几？

q006. 【计算题｜难度 3】计算：2/3 + 3/8 = ?

## 答案与解析

### A 层

**q001 答案：** 1/2
1. 把 2/5 通分为 4/10。
2. 4/10 + 1/10 = 5/10。
3. 5/10 约分为 1/2。
讲评提示：这题用于检查学生是否有化简意识。

**q002 答案：** 3/4 千米
1. 求一共走了多少，用加法：1/4 + 1/2。
2. 把 1/2 通分为 2/4。
3. 1/4 + 2/4 = 3/4 千米。
讲评提示：答案必须带“千米”。

**q003 答案：** 5/7
1. 分母相同，分数单位都是 1/7，直接把分子相加。
2. 2 + 3 = 5，所以 2/7 + 3/7 = 5/7。
讲评提示：追问学生：为什么不能把分母 7 也加上去？

**q004 答案：** 不对。3/10 + 7/10 = 10/10 = 1。
1. 同分母分数相加，分母不变，分子相加。
2. 3 + 7 = 10，分母还是 10，所以是 10/10 = 1。
3. 小红错误地把分母也相加了。
讲评提示：用此题诊断学生是否真正理解分数单位。

### B 层

**q005 答案：** 一共用去 5/12，还剩 7/12。
1. 先求用去总量：1/6 + 1/4 = 2/12 + 3/12 = 5/12。
2. 把整桶油看作 1，即 12/12。
3. 12/12 - 5/12 = 7/12。
讲评提示：两步题要求学生写清先后顺序。

**q006 答案：** 1又1/24
1. 3 和 8 的公分母可以取 24。
2. 2/3 = 16/24，3/8 = 9/24。
3. 16/24 + 9/24 = 25/24 = 1又1/24。
讲评提示：提醒学生结果大于 1 时要会解释数量意义。
