## 二、双学科教材分析

### 主学科：

| 维度 | 内容 |
| :--- | :--- |
| 单元定位 | 教科版五年级下册第三单元——环境与我们 |
| 课标要求 | 能基于真实生活问题收集数据，分析资源使用现象，并提出改进方案。 |

### 关联学科：

| 维度 | 内容 |
| :--- | :--- |
| 单元定位 | 人教版五年级下册第七单元——统计 |
| 课标要求 | 能收集、整理和表示简单数据，并结合数据作出解释。 |

### 课标交汇依据

两学科在'数据驱动决策'层面交汇：科学提供调查目的与解释框架，数学提供数据处理与可视化工具，共同服务于解决校园节水实际问题。

## 三、学科关联与融合设计

### 学科关联

| 学科 | 贡献 | 课标依据 |
| :--- | :--- | :--- |
| 科学（主学科） | 提供调查背景、问题定义及节水方案的科学性依据。 | std-sci-g6-water-001 |
| 数学（关联学科） | 提供数据整理规则、统计图选择标准及数据可视化方法。 | std-math-g5-data-001 |

### 融合节点

| 节点 | 描述 | 关联活动 |
| :--- | :--- | :--- |
| node-1 | 学生用数学图表呈现校园用水调查结果，再用科学视角提出节水方案。 | act-2；act-3 |

### 共同产出

校园节水数据报告与改进建议海报

### 适用边界

适合简单调查和数据表达，不涉及复杂统计推断或专业水质检测。

## 四、学情分析

| 维度 | 分析 |
| :--- | :--- |
| 主学科预备水平 | 学生已具备基本的观察记录能力，知道水资源的重要性，但缺乏系统的数据调查经验。 |
| 关联学科预备水平 | 学生已学习过条形统计图和折线统计图，能进行简单的数据读取与绘制。 |
| 跨学科思维经验 | 较少有将数学图表直接用于科学结论推导的经验，容易割裂看待数据与现象。 |

## 五、核心素养目标

| 维度 | 具体表现 |
| :--- | :--- |
| 科学观念 | 认识到水资源是有限的，理解校园用水现状与环境的关系。 |
| 探究实践 | 能利用数学工具整理调查数据，并用图表形式呈现调查结果。 |
| 态度责任 | 基于数据分析结果，主动提出可行的校园节水改进建议。 |
| 数据意识 | 体会数据在科学决策中的支撑作用，能选择合适图表表达信息。 |

## 六、教学目标

| 目标 | 归属学科 | 行为动词 | 评价证据 |
| :--- | :--- | :--- | :--- |
| 能分类整理校园不同区域的用水观察数据，制作成统计表。 | 数学 | 整理 | rubric-1 |
| 能根据数据特点选择合适的统计图，并准确绘制图表。 | 数学 | 设计 | rubric-1 |
| 能分析图表中的数据特征，解释校园用水浪费的主要原因。 | 科学+数学 | 分析 | rubric-2 |
| 能基于数据分析结果，提出具体的校园节水改进建议。 | 科学 | 设计 | rubric-2 |

### 教学重点

融合节点：学生用数学图表呈现校园用水调查结果，再用科学视角提出节水方案。

### 教学难点

交汇处认知负荷：如何引导学生从'看图说话'转向'数据归因'，避免图表与科学结论脱节。

## 七、融合教学流程

| 环节 | 时长 | 学科归属 | 教师活动 | 学生活动 | 产出 |
| :--- | ---: | :--- | :--- | :--- | :--- |
| 情境导入与任务发布 | 5 | 科学 | 展示校园水龙头滴水、长流水照片；发布任务：我们需要一份数据报告来说服学校改进用水设施 | 观察照片，讨论浪费现象；明确小组分工与调查目标 | 小组调查计划表 |
| 数据整理与图表制作 | 15 | 数学 | 提供已有的一周校园用水观察数据；指导选择条形图或折线图表达趋势；巡视指导图表规范性（标题、单位、刻度） | 分组整理数据至电子表格或纸质表；绘制统计图，标注关键数据点 | 校园用水数据统计表；用水情况统计图 |
| 数据分析与方案设计 | 15 | 学科交汇 | 提问引导：哪个时间段用水量最大？为什么？；提示结合科学常识（如蒸发、设备老化）解释数据异常；协助完善节水措施的可行性评估 | 解读图表，找出用水高峰和浪费点；结合科学原理提出具体节水措施；完成海报初稿 | 数据分析结论卡；节水建议海报 |
| 成果展示与评价 | 5 | 学科交汇 | 邀请两组展示海报；点评数据与结论的逻辑关联；总结跨学科解决问题的价值 | 汇报调查发现与建议；互评海报的数据准确性和建议可行性 | 互评反馈单 |

## 八、评价量规

| 维度 | 优秀 | 合格 | 待改进 | 证据来源 |
| :--- | :--- | :--- | :--- | :--- |
| 数据表达质量 | 图表类型选择恰当，数据准确无误，标注完整规范。 | 图表基本正确，数据无明显错误，标注较完整。 | 图表类型不当或数据错误较多，缺少必要标注。 | 统计图实物或电子文件 |
| 科学解释与建议 | 能从数据中准确归因，提出的建议具体可行且有科学依据。 | 能指出主要浪费点，建议较为合理但缺乏细节。 | 数据与结论脱节，建议空泛或缺乏科学依据。 | 数据分析结论卡与节水建议海报 |

## 十、教学反思要点

- 融合节点是否是完成核心任务的必要环节？（去掉关联学科后核心任务能否完成）
- 两个学科的知识是否在融合节点自然交汇？（还是简单的前半节A后半节B）
- 共同产出是否真正融合了两学科的方法和成果？（还是两学科产出的简单拼接）
