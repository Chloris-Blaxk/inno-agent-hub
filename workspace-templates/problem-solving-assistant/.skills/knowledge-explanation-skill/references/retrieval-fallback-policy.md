# 无知识库边界与降级策略

## 当前运行前提

当前默认没有可用知识库、题库、教材库、课标库、错因库或学生画像。Skill 不能执行真实检索，也不能假装已经检索。

本阶段内容依据只有：

1. 用户本轮输入。
2. 对话上下文。
3. 用户提供的题目、步骤、答案、错因或教材信息。
4. AI 的通用学科知识。
5. 本目录中的流程、风格和质检规则。

`knowledge-graph.json` 和 `knowledge-details.json` 只作为可选模拟资料或未来接入位置，不是当前默认必须命中的数据源。

## 来源披露

来源披露按使用场景区分，不把内部来源字段机械暴露给学生。

### 学生场景

- 默认不输出 `retrieved`、`inferred`、`generated_sample` 等字段名。
- 若是保守推断，用自然语言说明，例如：“我先按常见讲法来。”
- 若例题是临时生成样例，不声称它来自教材、真题或高频题；可以说“我们用一个小例子看”。

### 教师或调试场景

可以显式标记来源：

- `user_provided`：来自用户给出的题目、步骤或上下文。
- `ai_general_knowledge`：来自 AI 通用学科知识。
- `inferred`：依据年级、教材、题目内容做出的保守推断。
- `generated_sample`：没有真实数据时生成的样例。
- `retrieved`：仅在未来真实接入数据资源时使用。

禁止把生成样例伪装成真题、教材原题、课标条目或题库高频题。

## 最小可用结果

无知识库时，只要能够通过用户输入和通用学科知识补齐以下最小判断，就可以生成一轮讲解：

```json
{
  "target": "本轮知识点或题目卡点",
  "knowledgeType": "概念 / 规则 / 步骤 / 例题 / 错误过程 / 总结",
  "likelyPrerequisite": "可能的最小前置，可为空",
  "teachingMove": "本轮一个教学动作",
  "checkPoint": "结尾一个问题或判断"
}
```

不需要也不应该编造：

- 标准知识点 ID。
- 教材位置。
- 课标条目。
- 题库来源。
- 高频错因统计。
- 学生长期画像。

## 缺失信息时的处理

### 缺少年级或教材

- 如果不影响当前小步讲解，先按通用口径讲一个很小的点。
- 如果会影响难度、术语或是否超纲，只问一个确认问题。
- 不编造教材版本、单元或课时。

### 缺少题目

- 用户要求讲题但没有题目时，先要完整题目。
- 不补造题干、不虚构已知条件。

### 知识点歧义

- 如果题目文本能支撑，优先选一个最可能的主知识点。
- 否则只问一个关键澄清问题，并在本轮停止。

### 前置关系不确定

- 用通用学科知识保守推断最小前置。
- 如果前置会显著影响讲法，用一个短问题确认。
- 不声称该前置来自知识图谱。

### 缺少例题或检验题

- 可以临时生成一个最小微例、正例/反例或检查问题。
- 学生场景不必标注字段，但不能说它是真题、教材题或题库高频题。
- 教师或调试场景可标为 `generated_sample`。

### 缺少错因标签

- 只能根据学生给出的错误步骤和常见学科规律做保守分析。
- 可以说“问题可能卡在这一步”，不要说“这是高频错因”。
- 只修当前最关键一小步。
