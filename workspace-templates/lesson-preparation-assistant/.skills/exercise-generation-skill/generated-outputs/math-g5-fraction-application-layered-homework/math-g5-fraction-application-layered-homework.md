## 题目

### A 层

q001. 【应用题｜难度 2】小华走了 1/4 千米，又走了 1/2 千米。他一共走了多少千米？

q002. 【应用题｜难度 2】一本书，第一天看了 5/6，第二天比第一天少看了 1/3。第二天看了全书的几分之几？

q003. 【应用题｜难度 1】一块蛋糕，小明吃了 1/5，小红吃了 2/5。两人一共吃了这块蛋糕的几分之几？

### B 层

q004. 【应用题｜难度 3】一桶油，第一次用去 1/6，第二次用去 1/4。两次一共用去几分之几？还剩几分之几？

q005. 【应用题｜难度 3】一个小组计划完成实验记录的 3/5，已经完成了 1/4。还需要完成几分之几才能达到计划？

q006. 【应用题｜难度 2】一本书，上午看了 2/7，下午看了 1/7。一天共看了几分之几？还剩几分之几没看？

### C 层

q007. 【比较题｜难度 4】比较 1/2 + 1/6 和 3/4 - 1/8 的大小，并说明相差多少。

q008. 【判断题｜难度 4】一个项目已经完成 1/4，又完成 5/12。小林说：“已经超过 2/3 了。”他说得对吗？请说明理由。

q009. 【填空题｜难度 4】一次活动中，阅读安排了 1/6，讨论安排了 1/4。如果希望阅读、讨论和展示三项一共占 3/4，展示应安排多少？

## 答案与解析

### A 层

**q001 答案：** 3/4 千米
1. 求一共走了多少，用加法：1/4 + 1/2。
2. 把 1/2 通分为 2/4。
3. 1/4 + 2/4 = 3/4 千米。
讲评提示：答案必须带“千米”。

**q002 答案：** 1/2
1. 求第二天看了多少，用减法：5/6 - 1/3。
2. 1/3 = 2/6。
3. 5/6 - 2/6 = 3/6 = 1/2。
讲评提示：圈出“比第一天少”帮助判断运算。

**q003 答案：** 3/5
1. 求一共吃了多少，用加法：1/5 + 2/5。
2. 同分母分数相加，得到 3/5。
讲评提示：追问“3/5 是谁的 3/5”。

### B 层

**q004 答案：** 一共用去 5/12，还剩 7/12。
1. 先求用去总量：1/6 + 1/4 = 2/12 + 3/12 = 5/12。
2. 把整桶油看作 1，即 12/12。
3. 12/12 - 5/12 = 7/12。
讲评提示：两步题要求学生写清先后顺序。

**q005 答案：** 7/20
1. 求还差多少，用减法：3/5 - 1/4。
2. 通分为 12/20 - 5/20。
3. 结果是 7/20。
讲评提示：区别“达到计划”与“完成全部”。

**q006 答案：** 共看了 3/7，还剩 4/7。
1. 先求共看：2/7 + 1/7 = 3/7。
2. 把全书看作 1，即 7/7。
3. 7/7 - 3/7 = 4/7。
讲评提示：引导学生使用“已看 + 未看 = 1”。

### C 层

**q007 答案：** 1/2 + 1/6 更大，相差 1/24。
1. 1/2 + 1/6 = 3/6 + 1/6 = 4/6 = 2/3。
2. 3/4 - 1/8 = 6/8 - 1/8 = 5/8。
3. 2/3 = 16/24，5/8 = 15/24，所以前者大 1/24。
讲评提示：要求学生把比较过程写完整。

**q008 答案：** 不对，正好完成 2/3，没有超过。
1. 已完成：1/4 + 5/12 = 3/12 + 5/12 = 8/12。
2. 8/12 约分为 2/3。
3. 所以正好是 2/3，不是超过 2/3。
讲评提示：注意判断题需要准确表述。

**q009 答案：** 1/3
1. 先求阅读和讨论共占多少：1/6 + 1/4 = 2/12 + 3/12 = 5/12。
2. 展示应占：3/4 - 5/12。
3. 3/4 = 9/12，9/12 - 5/12 = 4/12 = 1/3。
讲评提示：这是逆向应用题，先明确目标总量。
