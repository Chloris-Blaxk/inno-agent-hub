# Education Mixed Methods Design

## Goal

Design a mixed-methods study where quantitative and qualitative strands answer one integrated research purpose.

## Inputs

- Research questions
- Quantitative variables/data
- Qualitative phenomenon/data
- Time/resources
- Which strand is dominant, if any

## Workflow

1. Choose design:
   - Explanatory sequential: QUAN -> qual
   - Exploratory sequential: QUAL -> quan
   - Convergent parallel: QUAN + QUAL
   - Embedded: one strand nested in intervention/evaluation
2. Define integration point: design, sampling, analysis, interpretation, or reporting.
3. Align data sources to subquestions.
4. Plan separate analyses and integrated joint display.
5. Draft mixed-methods method section.

## Tool Calls

Quantitative:

```text
SPSS, R, jamovi, JASP
```

Qualitative:

```text
NVivo, MAXQDA, ATLAS.ti, Dedoose
```

Joint displays:

```text
Excel/Sheets, R gt/flextable, PowerPoint, Mermaid
```

## Output Format

| Strand | Question | Data | Analysis | Integration Role |
|---|---|---|---|---|

Include:

- Mixed-methods design rationale
- Sequence diagram
- Joint display template
- Integration discussion prompts

## Quality Rules

- Mixed methods requires integration, not just two separate studies.
- State priority and sequence clearly.
- Explain contradictions between strands rather than hiding them.
