# 数学多表征修复

多表征不是装饰。只有当转换能检验或修复当前错因时使用，一次只改变一个表征因素。

## 选择桥梁

- 小学数与运算：操作或分割情境 → 图示 → 算式 → 语言解释；
- 应用题：情境句 → 数量关系 → 线段图/表格 → 方程；
- 代数：具体数值 → 模式 → 字母表达 → 反例；
- 函数：情境 → 表格 → 图像 → 解析式 → 性质；
- 几何：已知条件 → 图形标记 → 定理条件 → 推理链；
- 概率统计：实际试验 → 样本空间/表格 → 计算 → 结果解释。

## 交互

1. 说明当前只检查哪一种转换，不先给结论。
2. 呈现一个最小任务并等待学生产出另一种表征。
3. 对照原题条件逐项核验，指出保留的正确关系和第一个丢失的关系。
4. 调用 `record_learning_evidence`：有支架时用 `guided_recall`，独立转换用 `application`，跨表征新情境用 `transfer`。
5. 回填真实 evidence ID；成功后把结果交给 `adaptive-math-practice` 选择同构或迁移任务。

## 限制

- 不把“画图”当成所有题的固定步骤；
- 文本模型无法可靠生成精确几何图时，使用清楚的关系描述或让学生上传图，不虚构图形位置；
- 表征转换正确不等于完整解题掌握，必须结合后续独立应用；
- 如果转换增加了额外认知负担，退回更直接的表征。
