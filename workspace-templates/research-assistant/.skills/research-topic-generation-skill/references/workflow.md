# 动态知识图谱选题工作流

本工作流来自“基于动态知识图谱的教育科研选题与研究缺口挖掘方法及装置”文档，并按 skill 调用压缩为 S1-S9。

## S1 构建与维护 DKG

源记录 JSON 结构：

```json
{
  "source_id": "policy:2025-001",
  "source_type": "政策文件",
  "source_trust": 0.9,
  "timestamp": "2025-03",
  "entities": [
    {"name": "人工智能赋能课堂评价", "type": "研究主题", "aliases": ["AI课堂评价"]}
  ],
  "relations": [
    {"source": "人工智能赋能课堂评价", "target": "形成性评价", "type": "关联"}
  ]
}
```

DKG 必须保留实体/关系的来源、时间戳、动态权重、争议标记、演化记录。权重采用“时间衰减 + 来源增益”，冲突对象写入 `disputed` 与 `dispute_info`。

## S2 请求解析

请求字段：

- `theme`：主题或关键词，必填。
- `scene`：研究场景/限定条件。
- `preference`：总结性或规划性、方法偏好、输出数量。
- `identity`：教师资源约束或阶段约束。

缺省字段必须进入 `fallback_flags`。不要静默编造学科、样本、学校条件或政策依据。

## S3 锚点定位与子图抽取

1. 在 DKG 的实体名称、别名、类型中召回锚点。
2. 结合 `theme`、`scene`、`keywords` 做相似度重排。
3. 抽取锚点 K 跳局部子图。
4. 按时间窗、主题相关性、边权或 Top-M 做递进裁剪。
5. 锚点不足时可放宽阈值，但必须记录回退标记。

## S4 拓扑证据

必算：

- 邻域密度、带权密度
- 节点度
- 连通分量、最大分量占比、可达对比例

可算：

- 聚类系数
- k-core 核心层级
- 标签传播社团
- 介数中心性
- Burt 结构约束

## S5 缺口类型

- 稀疏区域型：邻域密度、带权密度、聚类、核心层级、节点度分位等至少两个指标共同触发。
- 结构洞型：跨社团、未直接连接、存在共同邻居，并结合介数中心性或结构约束判断潜在桥接机会。

每个缺口要生成成因要素：触发依据、缺口两侧实体、与用户请求的关系。

## S6 趋势证据

可选方法：

- 时间序列热度：按节点/关系出现年份构造热度，计算趋势斜率。
- 关系演化：对结构洞缺失连接估计潜在连接概率。
- 融合：加权、置信度门控、规则优先。

信号不足时必须输出回退趋势结论和不确定性说明。

## S7 排序

综合评分由四项组成：

- `MatchScore`：候选缺口与主题/场景匹配度。
- `GapScore`：缺口强度。
- `TrendScore`：趋势潜力。
- `FeasibilityScore`：数据充分性、来源覆盖、争议惩罚、资源约束。

默认权重见 `assets/agent_config.json`。

## S8 证据链

证据链字段见 `references/scoring_and_evidence.md`。每个排序结果必须有一条对应证据链。

## S9 反馈闭环

反馈类型包括选择、收藏、否定、理由备注。正向反馈增强相关实体/关系权重，负向反馈衰减权重，并写入演化记录。
