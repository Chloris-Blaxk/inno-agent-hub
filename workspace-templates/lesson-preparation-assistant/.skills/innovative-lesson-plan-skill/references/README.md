# References

本目录保存创新教案 Skill 的首批模拟数据和规则。当前数据均为 mock data，用于跑通 PBL、跨学科、AI 融合三类创新教案生成闭环，后续可替换为真实数据底座。

## 文件说明

- `mock-curriculum.json`：模拟课标、知识点和教材进度。
- `design-scaffolds.json`：PBL、跨学科、AI 融合三类设计脚手架。
- `integration-patterns.json`：AI 融合点模式与跨学科真实关联样例。
- `lesson-plan-examples.json`：高质量教案 few-shot 样例。
- `action-verbs.json`：学习目标行为动词层级和学段上限。
- `export-rules.json`：Word-ready Markdown 导出结构规则。
- `innovation-type-guide.json`：阶段一创新类型决策、追问和确认摘要模板。
- `input-output-schema.md`：请求和输出结构约定。

这些 mock 文件对应规划中的 A1、A2、A3、C1、C2、C3、F3 数据资源类别；使用本 Skill 时不需要读取外部规划文档。
