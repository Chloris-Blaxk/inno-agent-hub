# 需求摘录：研究选题生成

来源：`科研智能体-需求分析(1).html` 中“研究选题生成”场景。

## 核心痛点

教师评职称需要论文选题和课题选题。核心矛盾不是缺题，而是不知道如何从已有积累中提炼选题：上过的课、写过的案例、发过的文章、做过的课题成果，汇总后能形成什么研究方向；未来又应往哪里深耕，才能兼顾创新和自身能力。

## 需求边界

- 输入：教师上传材料，包括已发表论文、上课案例、教学反思、课题成果等；同时补充最小教师画像。
- 输出 1：总结性选题，强调过去已有积累，将上课案例和研究积累归纳为当前阶段可申报方向。
- 输出 2：规划性选题，强调未来 1-3 年深耕方向，结合政策热点、立项题样本、学校实践问题和教师条件。
- 首批能力：重复度/差异化判断和可行性判断。
- 明确不承诺：完整研究空白检测、中标概率预测。

## 研发方向

双模式选题生成系统：

1. 总结性选题引擎：材料解析 -> 已有成果聚类 -> 研究轨迹归纳 -> 当前阶段可申报方向，并论证“已有 X 基础，距离 Y 选题还差 Z”。
2. 规划性选题引擎：最小教师画像 -> 政策热点对齐 -> 历年立项题相似度/差异化检查 -> 推荐未来深耕方向。

每个候选方向应附：

- 创新性说明
- 已有基础匹配度
- 可行性风险
- 下一步资料清单

## 数据资源优先级

1. 用户材料解析规范：论文、案例、反思、成果。
2. 最小教师画像 schema：学科、学段、学校条件、能力基础、可投入周期。
3. 政策热点与资助方向标签。
4. 历年立项题目样本。
5. 学校/区域实践问题库与创新性-可行性双维量规。
6. 文献元数据索引。
