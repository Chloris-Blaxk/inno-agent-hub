q003. 【应用题｜难度 2】一条彩带，小华剪去它的 \frac{1}{4} 做蝴蝶结，小丽剪去它的 \frac{1}{3} 做装饰。两人一共剪去了这条彩带的几分之几？

q004. 【应用题｜难度 3】一盒牛奶，小明喝了 \frac{1}{2}，小红喝了 \frac{1}{5}。谁喝得多？多喝了多少？

### C 层

q005. 【应用题｜难度 4】小华看一本故事书，第一天看了全书的 \frac{1}{4}，第二天看了全书的 \frac{2}{5}。如果这本书共有120页，那么还剩下多少页没有看？

q006. 【比较题｜难度 4】甲、乙两个工程队共同修一条路。甲队完成了全长的 \frac{3}{8}，乙队完成了全长的 \frac{2}{5}。请问：哪个队完成的更多？多出的部分占全长的几分之几？

## 答案与解析

### A 层

**q001 答案：** \frac{1}{2}
1. 求剩余长度，用减法：\frac{7}{8} - \frac{3}{8}。
2. 同分母分数相减，得到 \frac{4}{8}。
3. 将 \frac{4}{8} 约分为最简分数 \frac{1}{2}。
讲评提示：强调同分母分数减法的计算法则，以及结果必须化为最简分数。

**q002 答案：** \frac{7}{12}
1. 求一共喝了多少，用加法：\frac{1}{3} + \frac{1}{4}。
2. 异分母分数相加，先通分：\frac{4}{12} + \frac{3}{12}。
3. 计算得到 \frac{7}{12}。
讲评提示：重点讲解异分母分数加法的通分方法，强调必须先统一分数单位再计算。

### B 层

**q003 答案：** \frac{7}{12}
1. 求一共剪去多少，用加法：\frac{1}{4} + \frac{1}{3}。
2. 通分：\frac{3}{12} + \frac{4}{12} = \frac{7}{12}。
讲评提示：引导学生注意异分母分数加法的通分步骤，强调结果要化为最简分数。

**q004 答案：** 小明喝得多，多喝了 \frac{3}{10}
1. 比较 \frac{1}{2} 和 \frac{1}{5} 的大小：\frac{1}{2} = \frac{5}{10}，\frac{1}{5} = \frac{2}{10}，所以 \frac{1}{2} > \frac{1}{5}。
2. 计算差值：\frac{1}{2} - \frac{1}{5} = \frac{5}{10} - \frac{2}{10} = \frac{3}{10}。
讲评提示：通过具体情境帮助学生理解分数大小比较和减法运算，提醒学生注意通分和计算的准确性。

### C 层

**q005 答案：** 42
1. 方法一：先求已看部分占全书的比例，再求剩余页数。
2. 已看比例：\frac{1}{4} + \frac{2}{5} = \frac{5}{20} + \frac{8}{20} = \frac{13}{20}。
3. 剩余比例：1 - \frac{13}{20} = \frac{7}{20}。
4. 剩余页数：120 \times \frac{7}{20} = 42（页）。
5. 方法二：先分别计算两天看的页数，再求剩余页数。
6. 第一天看：120 \times \frac{1}{4} = 30（页）。
7. 第二天看：120 \times \frac{2}{5} = 48（页）。
8. 剩余页数：120 - 30 - 48 = 42（页）。
9. 两种方法结果一致，验证答案正确。
讲评提示：本题是分数应用题与整数乘法的综合，旨在考察学生将抽象分数与具体数量结合的能力。教学时可引导学生理解‘单位1’（全书页数）的重要性，并鼓励用不同方法解题，培养思维的灵活性。强调审题，特别是‘还剩下’这个关键词。

**q006 答案：** 乙队完成的更多，多出的部分占全长的 \frac{1}{40}。
1. 第一步：比较 \frac{3}{8} 和 \frac{2}{5} 的大小。
2. 通分：\frac{3}{8} = \frac{15}{40}，\frac{2}{5} = \frac{16}{40}。
3. 因为 \frac{16}{40} > \frac{15}{40}，所以乙队完成的更多。
4. 第二步：计算多出的部分。
5. 用乙队完成的比例减去甲队完成的比例：\frac{2}{5} - \frac{3}{8} = \frac{16}{40} - \frac{15}{40} = \frac{1}{40}。
6. 答：乙队完成的更多，多出的部分占全长的 \frac{1}{40}。
讲评提示：本题考察异分母分数的比较和减法运算，是分数应用题中的常见题型。教学时应强调‘比较大小’和‘求差’是两个不同的步骤，引导学生先比较再计算。可以通过画线段图的方式，帮助学生直观理解两个分数所代表的部分以及它们之间的差值。
