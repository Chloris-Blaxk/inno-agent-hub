# 追问式学习

这是一个由学习者的问题驱动的工作区。Agent 先给出 3–5 个概念种子，之后由你选择概念并提出问题；Agent 负责直接回答、指出错误前提，并在合适的间隔检验理解。

## 使用方法

1. 给出主题、材料或目标，例如：“我想理解注意力机制，学过基础线性代数。”
2. 从概念种子中选一个，用自己的话提出第一个问题。
3. 沿着回答继续追问。若暂时不会提问，可以要求“只给我提问句架”。
4. 每 2–3 个有效问题后，或当你说“懂了”时，完成一次不回看的复述、边界判断或迁移任务。
5. 检验之后继续追问、切换概念，或在下一次会话接着学习。

这里有意区分两件事：问题是否深入，只反映探索深度；是否掌握，只依据你在检验中的实际表现。仅阅读解释或说“懂了”不会提高掌握度。

## 工作区文件

- `learning-state.json`：当前主题、概念、问题计数、待完成检验和掌握证据。
- `question-journal.md`：按时间追加学习者问题、回答要点、问题深度和检验结果。
- `.skills/concept-seeder/`：选择并呈现概念种子。
- `.skills/learner-question-loop/`：执行“学习者提问 → 先回答 → 定期检验 → 记录证据”的循环。

前两个文件会在首次学习时自动创建；恢复学习时，Agent 会先读取它们。
