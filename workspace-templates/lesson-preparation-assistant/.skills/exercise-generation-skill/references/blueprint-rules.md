# 出题蓝图规则

## 共同规则

- 先锁定课标、教材单元和知识点边界，再选择题型和难度。
- 每道题必须能回链到至少一个 `knowledgePointId`。
- 首批不承诺真实测量学区分度，难度和分层使用规则标签近似。
- 题目生成优先使用结构化种子题和模板变式，避免临场无约束编题。
- 试卷型产物必须输出题型比例、难度比例、覆盖检查和讲评建议。
- 请求可提供 `layerMix`、`questionTypeMix`、`difficultyMix` 作为蓝图目标。
- 默认 `strictBlueprint=false`：比例不完全命中时记录 `warn`；设为 `true` 时比例偏差会导致校验失败。

## classroom_practice

- 默认 5-8 题。
- 难度以 1-3 为主。
- 适合当堂诊断、随堂练习和出口测。
- 输出重点是即时反馈和常见错因提醒。

## layered_homework

- 默认 A/B/C 三层。
- A 层：基础模仿，难度 1-2，检查概念和基本方法。
- B 层：巩固迁移，难度 2-3，含一步应用或常见变式。
- C 层：拓展挑战，难度 3-4，含多步推理、比较或开放解释。
- 每层至少 2 题；若请求题量不能整除层数，优先补给 B 层，再补给 C 层。

## unit_test / stage_test

- 默认 12-20 题。
- 难度建议：基础 50%，巩固 35%，拓展 15%。
- 需要覆盖主要知识点，不能只围绕一个题型反复出题。
- 必须包含讲评建议，指出先讲哪些共性错因。

## topic_drill

- 围绕一个知识点或题型做变式。
- 默认 8-12 题。
- 题目应覆盖基础、易错、变式、应用四类。
- 输出重复风险检查，避免只是数值替换。
- 输出 `replacementSuggestions`，从相似题组中给出可换题源题。
