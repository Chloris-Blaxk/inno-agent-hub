# Education Policy Comparative Analysis

## Goal

Create a structured policy/comparative education analysis with clear cases, dimensions, evidence, and argument.

## Inputs

- Policy/topic/countries/regions
- Text corpus: laws, standards, guidelines, official reports, curricula
- Comparison dimension: goals, governance, equity, assessment, teacher policy, AI policy
- Time range

## Workflow

1. Define comparison cases and rationale.
2. Collect authoritative policy documents.
3. Build analysis framework/dimensions.
4. Code policy texts or extract evidence.
5. Compare similarities, differences, mechanisms, and implications.
6. Draft policy-analysis paper structure.

## Tool Calls

Policy/document management:

```text
Zotero, official ministry/agency websites, OECD/UNESCO/World Bank databases
```

Text coding:

```text
NVivo, MAXQDA, ATLAS.ti, Python NLP, R tidytext
```

Visualization:

```text
Excel/Sheets, Mermaid, Power BI
```

## Output Format

| Case/Policy | Dimension | Evidence | Interpretation |
|---|---|---|---|

Include:

- Corpus list
- Comparative framework
- Coding scheme
- Argument map
- Paper outline

## Quality Rules

- Use authoritative policy sources.
- Avoid normative claims without textual or contextual evidence.
- Make comparison dimensions symmetrical across cases.
