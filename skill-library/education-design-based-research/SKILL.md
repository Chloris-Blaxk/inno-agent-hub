# Education Design-Based Research

## Goal

Build a DBR plan that designs, implements, evaluates, and refines an educational intervention while producing practical and theoretical contributions.

## Inputs

- Educational problem
- Proposed design artifact: tool, course, lesson model, AI workflow, learning environment
- Context and participants
- Iteration timeline
- Evidence sources

## Workflow

1. Define practical problem and theoretical grounding.
2. Propose initial design principles.
3. Design prototype/intervention.
4. Plan iterative cycles: design -> enact -> analyze -> redesign.
5. Specify data sources for usability, learning process, and outcomes.
6. Produce DBR paper structure and design-principle table.

## Tool Calls

Design/prototyping:

```text
Figma, Miro, FigJam, Notion
```

Data:

```text
Classroom observation, interviews, learning artifacts, platform logs, pre/post assessment
```

Analysis:

```text
NVivo/MAXQDA for qualitative process data; R/SPSS for outcome data
```

## Output Format

| Iteration | Design Principle | Implementation | Evidence | Revision |
|---|---|---|---|---|

Include:

- DBR rationale
- Design principles
- Iteration plan
- Data plan
- Theoretical contribution statement

## Quality Rules

- DBR is not only product design; it must generate transferable design knowledge.
- Use authentic educational settings where possible.
- Show how evidence changes the design.
