# 拍题答疑辅导 Skill

面向拍题答疑场景的智能辅导系统，根据学生作答状态提供分级提示、错步诊断和相似题推荐。

---

## 功能特性

- ✅ **未作答分级提示** - 多轮苏格拉底式引导，逐步启发思路
- ✅ **已作答错步诊断** - 精准定位第一处错误，分析错因，给出正确做法
- ✅ **相似题推荐** - 根据知识点、方法、难度智能推荐练习题
- ✅ **多轮交互** - 根据学生回复动态调整引导节奏和深度
- ✅ **风格可选** - 支持通用风格、李永乐风格、罗翔风格、张雪峰风格

---

## 适用学科

本 Skill 采用**步骤诊断范式**，适合有明确解题步骤和标准答案的题目类型。

### ⭐⭐⭐⭐⭐ 完全适配（核心学科）

**数学**
- 计算题、应用题、几何证明
- 所有功能完全可用

### ⭐⭐⭐⭐ 高度适配

**物理**
- 公式推导、计算题、实验步骤分析
- 需补充物理特定错误模式

**化学**
- 化学方程式配平、计量计算、实验设计
- 需补充化学特定错误模式

**人工智能教育**
- 算法设计、编程实现、模型训练流程、数据处理
- 需补充 AI 特定错误模式（过拟合、数据泄露等）

### ⭐⭐⭐ 部分适配（客观题适用）

**英语**
- ✅ 适用：语法改错、句型转换、完形填空
- ❌ 不适用：作文批改、口语评估

**生物学**
- ✅ 适用：遗传计算、实验步骤、概念推理
- ❌ 不适用：开放性描述题

**信息技术**
- ✅ 适用：编程题、算法题、逻辑设计
- ❌ 不适用：软件操作题

### ⭐⭐ 少量适配

**语文**
- ✅ 适用：文言文翻译、病句修改
- ❌ 不适用：阅读理解主观题、作文

**地理**
- ✅ 适用：计算题（时差、比例尺）、地图题
- ❌ 不适用：区域分析开放题

**历史**
- ✅ 适用：材料分析题的要点提取
- ❌ 不适用：历史论述题

### ⭐ 极少适用

**道德与法治** - 概念辨析可用，价值判断题不适用  
**劳动教育** - 理论知识可用，实践技能不适用

### ❌ 不适用

**体育与健康** - 需要视频分析  
**音乐** - 需要音频分析（乐理题除外）  
**美术** - 需要图像分析（理论题除外）  
**综合实践活动** - 无标准答案

## 使用方式

### 基本输入格式

**注意：** 所有输入模式中的 `subject` 字段都是可选的。智能体会自动从题目内容中识别学科类型，无需用户手动指定。

#### 1. 未作答场景

学生只发题目或表示"不会"、"没思路"：

```json
{
  "mode": "unanswered_hint",
  "grade": "五年级",
  "question": "计算 1/2 + 1/3 = ?",
  "hintLevel": 1,
  "knowledgePointIds": ["math-g5-fraction-add"],
  "teachingStyle": "neutral"
}
```

#### 2. 已作答场景

学生提供了答案或解题步骤：

```json
{
  "mode": "diagnose_answer",
  "grade": "五年级",
  "question": "计算 1/2 + 1/3 = ?",
  "studentAnswer": {
    "answerText": "分母相加2+3=5，分子相加1+1=2，答案2/5"
  },
  "teachingStyle": "gentle"
}
```

#### 3. 只请求相似题

```json
{
  "mode": "request_similar",
  "grade": "五年级",
  "knowledgePointIds": ["math-g5-fraction-add"],
  "difficulty": 2,
  "count": 3
}
```

## 教学风格

支持多种教学风格，在 `teachingStyle` 参数中指定：

### `"neutral"`（默认）

标准、清晰、中性的教学表达，无个性化标签。

**示例：**
```
我看了你的解答。你是把分母相加（2+3=5），分子相加（1+1=2），得到 2/5。

问题出在第一步——异分母分数不能直接把分母相加。就像你不能把"2个苹果"和"3个橙子"直接加成"5个什么"，单位不一样不能直接合并。

正确的做法是先通分，找到最小公倍数6作为公分母，1/2=3/6，1/3=2/6，相加得5/6。答案是 5/6。

这个错误的原因你明白了吗？
```

---

### `"gentle"` - 温和型风格

亲和、生动、深入浅出，擅长用生活化类比讲解抽象概念。

**特点：** "咱们"、"对吧"、"是不是"，生活化类比，温和确认

**参考来源：** 参考李永乐老师教学风格

**示例：**
```
咱们来看看你的解答。你是把分母直接加了（2+3=5），分子也加了（1+1=2），得到2/5，是不是？

这个想法我能理解，但问题在于——分母其实不能直接相加。为什么呢？咱们打个比方，就像你去买水果，一个摊位说"2块钱一斤苹果"，另一个说"3块钱一斤橙子"，你能说"一共5块钱一斤"吗？不能，对吧？

分数也是这样。1/2 的分数单位是"二分之一"，1/3 的分数单位是"三分之一"，它们不一样，得先统一。怎么统一呢？找最小公倍数6，然后把它们都变成"六分之几"：1/2=3/6，1/3=2/6，这样就能加了，3/6+2/6=5/6。

你看，是不是就清楚了？
```

---

### `"humorous"` - 幽默型风格

幽默、思辨、善于用思想实验和反证法引发思考。

**特点：** 思想实验、反证法、"看起来对但实际错"的转折

**参考来源：** 参考罗翔老师教学风格

**示例：**
```
同学，我看到你的解法了。分母相加，分子相加，得到2/5。逻辑上看起来很完美——但问题恰恰出在这个"看起来完美"上。

我们来做一个思想实验：如果你的方法是对的，那1/1 + 1/1 应该等于 2/2 = 1。但 1/1 就是 1，1+1应该等于2，不是1。你看，按照你的方法，1+1=1。这显然荒谬。

那问题出在哪呢？出在"分母不能直接相加"。分母代表的是"份"的大小——1/2 是"2份里取1份"，1/3 是"3份里取1份"。份的大小不一样，不能直接合并。必须先把份统一，也就是通分。找到公分母6，1/2=3/6，1/3=2/6，然后3/6+2/6=5/6。

这个逻辑你能接受吗？
```

---

### `"direct"` - 直率型风格

直率、激励、接地气，善于用"大白话"讲清楚复杂问题。

**特点：** "说白了"、"我直接告诉你"、重复强调、金句总结

**参考来源：** 参考张雪峰老师教学风格

**示例：**
```
你这步错了。说白了，就是分母直接加，分子直接加，得到2/5。这是最常见的错误，每年都有人犯。

我直接告诉你为什么错——单位不统一。单位不统一！听懂了吗？1/2 的单位是"二分之一"，1/3 的单位是"三分之一"，不一样。你想想，你去买东西，一个说"2块钱一斤"，另一个说"3块钱一公斤"，你能直接给5块钱吗？不能。为什么？单位不一样。

那怎么做？三步。第一步，找公倍数6。第二步，通分，1/2=3/6，1/3=2/6。第三步，相加，3/6+2/6=5/6。就这么简单。

记住了吗？记住了！以后遇到异分母分数加法，你就记住一句话：先通分，再相加。
```

## 核心特性

### 智能学科识别

无需用户指定学科，智能体通过以下方式自动识别：

- **关键词识别**：数学符号、物理单位、化学元素、编程关键词等
- **题型特征**：计算题、代码题、翻译题、实验题等
- **上下文推断**：结合年级和知识点进行学科判断

### 多轮交互协议

- 未作答时，通过多轮对话逐级引导（Level 1-4 内部状态）
- 已作答时，第一轮完整诊断，之后根据学生理解情况多轮引导纠错
- 根据学生每次回复动态调整节奏（快速通过、正常推进、停留拆分、重新引导）

### 输出风格

- 像真实老师口头反馈，不是书面报告
- 不重复学生已知信息（题目、答案）
- 不使用"## 步骤对照"、"## 错误定位"等结构化标题
- 2-4 个自然段落，简短流畅

## 技术特性

- **纯 Agent 驱动** - 无需外部 LLM 或 Python 脚本
- **OCR 支持** - 可识别图片中的题目和作答
- **知识库驱动** - 错误模式库、知识图谱、相似题库

## 常见问题

**Q: 为什么不支持作文批改？**  
A: 作文评估需要评价深度、广度、创意等主观维度，与当前的"步骤诊断"范式不同，需要专门的主观题评估模块。

**Q: 可以自定义教学风格吗？**  
A: 可以。参考 `references/teaching-styles/README.md` 中的扩展指南，按照模板创建新的风格文档。

**Q: 如何选择合适的教学风格？**  
A: 
- 需要建立直觉理解 → `gentle`（生活化类比）
- 需要纠正错误直觉 → `humorous`（反证法）
- 需要快速记忆要点 → `direct`（金句总结）
- 标准化场景 → `neutral`（默认）

**Q: 支持哪些输入格式？**  
A: 
- 文本输入：直接 JSON 格式
- 图片输入：通过 OCR API 识别
- 结构化步骤：`steps` + `finalAnswer`
- 连续文本：`answerText`（自动解析为步骤）

**Q: 如果智能体识别不出学科怎么办？**  
A: 系统会尝试从知识点ID或题目特征推断。如果仍无法识别，会使用通用诊断模式，或提示用户提供学科信息。

**Q: 如果错误模式库中没有匹配的错误类型怎么办？**  
A: 系统不会放弃诊断。即使找不到预定义的错误模式，智能体也会使用推理能力进行通用错误分析：对比学生步骤与标准步骤，找出差异并解释原因。错误模式库是辅助工具，不是必需品。

**Q: 某个学科的错误模式库还没创建怎么办？**  
A: 系统会降级到通用推理模式。智能体会基于题目逻辑和标准答案进行错误诊断，质量可能略低于有错误模式库的情况，但仍能提供有价值的反馈。

**Q: 学生的错误很复杂，有多处错误怎么办？**  
A: 系统遵循"第一错步定位"原则，只诊断第一处导致结果偏离的错误。避免信息过载，等学生理解并纠正第一处错误后，再通过多轮交互处理后续问题。
