# 课件生成场景痛点与数据缺口

## 来源范围

本 Skill 的场景依据来自 `agent_design/docs/11个教育智能体的场景痛点与数据缺口总览.json` 第 19-34 行，对应：

- 业务线：备课线
- 角色：教师
- 场景：课件生成

## 核心痛点

教师描述一个课题后，仍要逐页手动排版、找素材、设计互动环节。一节 40 分钟课件通常耗时 2-3 小时；不同课型不能直接套同一结构，教师需要反复改版。

## 需求判断

课件生成不是“给内容做美化”，而是：

1. 分析教师输入。
2. 生成结构化课堂大纲。
3. 基于大纲生成教师逐字稿。
4. 基于大纲和逐字稿生成可直接编辑和导出的 PPTX/Slides-ready 课件结构。
5. 使用适合教室投影的配色、字号、留白和页面密度。

## 首批研发方向

描述课题后，系统自动产出：

- 结构化课堂大纲；
- 教师逐字稿；
- 可编辑课件页面对象；
- 教学备注；
- 时间建议；
- 投影友好的版式约束；
- 可选基础互动组件。

## 关键数据资源

按紧迫度排序：

1. 教材单元与课时结构。
2. 课标目标与知识点边界。
3. 课型模板、页面结构块与时间分配。
4. 投影友好的配色与版式规则。
5. 可编辑 PPTX 输出结构、课件生成提示词与技能模板。
6. 基础课堂互动组件。

## 对 Skill 的设计影响

- `lesson-flow-templates.md` 承载课型模板与时间分配（5 种课型均有对应 build 函数）。
- `slide-layouts.md` 与 `lesson-layout-lock.md` 承载页面结构块（ED01-ED12）和素材槽位。
- `projection-style-rules.md` 承载投影配色、字号、留白和页面密度规则。
- `subject-knowledge-packs.json` 承载学科特定课堂素材（hook / concept / steps / tasks / misconception），未匹配课题自动回退泛用模板。
- `input-output-schema.md` 承载 PPTX/Slides-ready 输出结构。
- `quality-checklist.md` 负责防止课件只剩”好看但不好教”。
