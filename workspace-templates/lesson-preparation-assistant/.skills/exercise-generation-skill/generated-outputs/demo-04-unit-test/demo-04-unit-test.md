## 答案与解析

### A 层

**q001 答案：** \frac{3}{5}
1. 分母相同，分数单位都是 \frac{1}{5}，直接把分子相加。
2. 1 + 2 = 3，所以 \frac{1}{5} + \frac{2}{5} = \frac{3}{5}。
讲评提示：强调同分母分数加法时分母不变，只加分子。

**q002 答案：** \frac{3}{9}
1. 分母相同，分数单位都是 \frac{1}{9}，直接把分子相减。
2. 7 - 4 = 3，所以 \frac{7}{9} - \frac{4}{9} = \frac{3}{9}。
讲评提示：强调同分母分数减法时分母不变，只减分子。

**q003 答案：** \frac{3}{6}
1. 求剩余长度，用减法：\frac{5}{6} - \frac{2}{6}。
2. 分母相同，分子相减：5 - 2 = 3，得 \frac{3}{6} 米。
讲评提示：引导学生理解“剪掉”对应减法运算，并注意单位。

**q004 答案：** \frac{7}{8}
1. 分母相同，分数单位都是 \frac{1}{8}，直接把分子相加。
2. 3 + 4 = 7，所以 \frac{3}{8} + \frac{4}{8} = \frac{7}{8}。
讲评提示：强调同分母分数加法时分母不变，只加分子。

**q005 答案：** \frac{3}{4}
1. 求一共喝了多少，用加法：\frac{1}{4} + \frac{2}{4}。
2. 分母相同，分子相加：1 + 2 = 3，得 \frac{3}{4}。
讲评提示：引导学生理解“一共”对应加法运算，并注意单位。

**q006 答案：** \frac{6}{10}
1. 分母相同，分数单位都是 \frac{1}{10}，直接把分子相减。
2. 9 - 3 = 6，所以 \frac{9}{10} - \frac{3}{10} = \frac{6}{10}。
讲评提示：强调同分母分数减法时分母不变，只减分子。

**q007 答案：** \frac{5}{7}
1. 求一共吃了多少，用加法：\frac{2}{7} + \frac{3}{7}。
2. 分母相同，分子相加：2 + 3 = 5，得 \frac{5}{7}。
讲评提示：引导学生理解“一共”对应加法运算，并注意单位。

**q008 答案：** \frac{11}{12}
1. 分母相同，分数单位都是 \frac{1}{12}，直接把分子相加。
2. 5 + 6 = 11，所以 \frac{5}{12} + \frac{6}{12} = \frac{11}{12}。
讲评提示：强调同分母分数加法时分母不变，只加分子。

### B 层

**q009 答案：** \frac{1}{3}
1. 按从左到右顺序计算：\frac{5}{9} + \frac{2}{9} = \frac{7}{9}。
2. \frac{7}{9} - \frac{4}{9} = \frac{3}{9}。
3. 将 \frac{3}{9} 约分为最简分数 \frac{1}{3}。
讲评提示：强调同分母分数加减法的运算顺序和结果必须化为最简分数。

**q010 答案：** \frac{5}{8}
1. 分母不同，需要先通分。4和8的最小公倍数是8。
2. 将 \frac{1}{4} 转化为 \frac{2}{8}。
3. \frac{2}{8} + \frac{3}{8} = \frac{5}{8}。
讲评提示：重点讲解通分的必要性和方法，强调通分时分子分母要同乘一个数。

**q011 答案：** \frac{7}{12}
1. 求一共喝了多少，用加法：\frac{1}{3} + \frac{1}{4}。
2. 分母不同，先通分。3和4的最小公倍数是12。
3. 将 \frac{1}{3} 转化为 \frac{4}{12}，将 \frac{1}{4} 转化为 \frac{3}{12}。
4. \frac{4}{12} + \frac{3}{12} = \frac{7}{12}。
讲评提示：引导学生理解实际问题中的分数加法，强调通分在解决异分母分数加法中的关键作用。

**q012 答案：** \frac{1}{5}
1. 先算两次一共用去多少：\frac{2}{10} + \frac{3}{10} = \frac{5}{10}。
2. 再算还剩多少：\frac{7}{10} - \frac{5}{10} = \frac{2}{10}。
3. 将 \frac{2}{10} 约分为最简分数 \frac{1}{5}。
讲评提示：培养学生分步解决问题的能力，同时强调结果的最简形式。

**q013 答案：** \frac{1}{6}
1. 把整块地看作单位 1。
2. 先算玉米和大豆一共占多少：\frac{1}{2} + \frac{1}{3}。
3. 通分：\frac{3}{6} + \frac{2}{6} = \frac{5}{6}。
4. 再算蔬菜占多少：1 - \frac{5}{6} = \frac{6}{6} - \frac{5}{6} = \frac{1}{6}。
讲评提示：引导学生理解单位1在分数应用题中的作用，巩固异分母分数加减法的综合运用。

### C 层

**q014 答案：** 小红喝得多，多 \frac{1}{15} 杯。
1. 比较 \frac{1}{3} 和 \frac{2}{5} 的大小，需要先通分。
2. 3 和 5 的最小公倍数是 15，所以 \frac{1}{3} = \frac{5}{15}，\frac{2}{5} = \frac{6}{15}。
3. 因为 \frac{6}{15} > \frac{5}{15}，所以小红喝得多。
4. 计算多多少：\frac{6}{15} - \frac{5}{15} = \frac{1}{15}。
讲评提示：本题考察异分母分数的比较和减法运算。教学时应强调通分的必要性，并引导学生理解分数单位的变化。

**q015 答案：** 不对。a 和 b 可以是 1 和 6、2 和 5、3 和 4、4 和 3、5 和 2、6 和 1 等多种组合。
1. 根据同分母分数加法法则，\frac{a}{8} + \frac{b}{8} = \frac{a+b}{8}。
2. 题目给出 \frac{a+b}{8} = \frac{7}{8}，所以 a + b = 7。
3. a 和 b 是正整数，满足 a + b = 7 的组合有：(1,6)、(2,5)、(3,4)、(4,3)、(5,2)、(6,1)。
4. 因此原说法不全面，是错误的。
讲评提示：本题考察同分母分数加法的逆向思维和开放性思考。教学时应鼓励学生全面考虑所有可能性，培养严谨的数学思维。
