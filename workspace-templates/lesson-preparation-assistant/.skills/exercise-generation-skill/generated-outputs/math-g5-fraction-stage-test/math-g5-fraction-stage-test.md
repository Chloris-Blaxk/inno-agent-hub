## 答案与解析

### A 层

**q001 答案：** 3/4 千米
1. 求一共走了多少，用加法：1/4 + 1/2。
2. 把 1/2 通分为 2/4。
3. 1/4 + 2/4 = 3/4 千米。
讲评提示：答案必须带“千米”。

**q002 答案：** 3/5
1. 求一共吃了多少，用加法：1/5 + 2/5。
2. 同分母分数相加，得到 3/5。
讲评提示：追问“3/5 是谁的 3/5”。

**q003 答案：** 1/2
1. 把 2/5 通分为 4/10。
2. 4/10 + 1/10 = 5/10。
3. 5/10 约分为 1/2。
讲评提示：这题用于检查学生是否有化简意识。

**q004 答案：** 5/8
1. 把整根木条看作 1，即 8/8。
2. 8/8 - 3/8 = 5/8。
讲评提示：让学生先写“还剩 = 1 - 用去”。

**q005 答案：** 2/5
1. 分母相同，分子相减：7 - 3 = 4，得 4/10。
2. 4/10 约分，分子分母同时除以 2，得 2/5。
讲评提示：提醒学生最后一步检查能否约分。

**q006 答案：** 5/7
1. 求一天共用多少，用加法：2/7 + 3/7。
2. 同分母相加，得 5/7。
讲评提示：提醒学生答案不是“5”，而是“5/7”。

**q007 答案：** 1/2
1. 1/3 = 2/6。
2. 5/6 - 2/6 = 3/6。
3. 3/6 约分，得 1/2。
讲评提示：提醒学生最后检查能否约分。

**q008 答案：** 5/9
1. 把整个图形看作 1，即 9/9。
2. 9/9 - 4/9 = 5/9。
讲评提示：可配合画图解释整体 1。

### B 层

**q009 答案：** 2/9
1. 把 1 化成 9/9。
2. 9/9 - 2/9 = 7/9。
3. 7/9 - 5/9 = 2/9。
讲评提示：也可以先算 2/9 + 5/9 = 7/9，再用 1 - 7/9 = 2/9。

**q010 答案：** 一共耕了 5/8，还剩 3/8。
1. 先求一共耕了多少：3/8 + 1/4。
2. 1/4 = 2/8，所以 3/8 + 2/8 = 5/8。
3. 再求剩下：1 - 5/8 = 3/8。
讲评提示：这是一步加法加一步补全整体的综合题。

**q011 答案：** 一样大，都等于 5/7。
1. 计算左边：3/7 + 2/7 = 5/7。
2. 计算右边：6/7 - 1/7 = 5/7。
3. 5/7 = 5/7，所以一样大。
讲评提示：引导学生发现：加法和减法可以得到相同的结果。

**q012 答案：** 1又1/24
1. 3 和 8 的公分母可以取 24。
2. 2/3 = 16/24，3/8 = 9/24。
3. 16/24 + 9/24 = 25/24 = 1又1/24。
讲评提示：提醒学生结果大于 1 时要会解释数量意义。

**q013 答案：** 1/2 米
1. 求还剩多少，用减法：7/8 - 3/8。
2. 7 - 3 = 4，得 4/8。
3. 4/8 约分，得 1/2 米。
讲评提示：提醒学生最后写单位和约分。

### C 层

**q014 答案：** 8种：1和8、2和7、3和6、4和5、5和4、6和3、7和2、8和1。
1. 设两个正整数为 a 和 b，则 a + b = 9，且 a ≠ b。
2. 正整数解有：(1,8)、(2,7)、(3,6)、(4,5)、(5,4)、(6,3)、(7,2)、(8,1)。
3. 共 8 种填法。
讲评提示：引导学生有序列举，避免重复和遗漏。

**q015 答案：** 不对，正好完成 2/3，没有超过。
1. 已完成：1/4 + 5/12 = 3/12 + 5/12 = 8/12。
2. 8/12 约分为 2/3。
3. 所以正好是 2/3，不是超过 2/3。
讲评提示：注意判断题需要准确表述。
