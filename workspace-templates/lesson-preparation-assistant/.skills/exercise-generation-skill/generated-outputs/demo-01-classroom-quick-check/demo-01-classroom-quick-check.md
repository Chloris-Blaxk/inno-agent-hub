## 题目

### A 层

q001. 【计算题｜难度 1】计算：\frac{4}{9} + \frac{2}{9} = ?

q002. 【应用题｜难度 2】一个水桶装了 \frac{3}{10} 的水，又倒入了 \frac{5}{10} 的水，现在水桶里有几分之几的水？

### B 层

q003. 【计算题｜难度 2】计算：\frac{4}{9} + \frac{2}{9} - \frac{1}{9} = ?

q004. 【应用题｜难度 3】一瓶果汁，小明喝了 \frac{3}{10}，小红喝了 \frac{4}{10}，还剩这瓶果汁的几分之几？

q005. 【判断题｜难度 2】判断对错：\frac{5}{12} + \frac{7}{12} = 1。

## 答案与解析

### A 层

**q001 答案：** \frac{6}{9}
1. 分母相同，分数单位都是 \frac{1}{9}，直接把分子相加。
2. 4 + 2 = 6，所以 \frac{4}{9} + \frac{2}{9} = \frac{6}{9}。
讲评提示：强调同分母分数加法的计算法则，提醒学生注意结果是否需要约分。

**q002 答案：** \frac{8}{10}
1. 求现在水桶里有多少水，用加法：\frac{3}{10} + \frac{5}{10}。
2. 分母相同，分子相加：3 + 5 = 8，得 \frac{8}{10}。
讲评提示：引导学生理解题目中的数量关系，明确是求总量，因此用加法。

### B 层

**q003 答案：** \frac{5}{9}
1. 按从左到右顺序计算：\frac{4}{9} + \frac{2}{9} = \frac{6}{9}。
2. \frac{6}{9} - \frac{1}{9} = \frac{5}{9}。
3. 注意：\frac{6}{9} 可以约分为 \frac{2}{3}，但本题要求同分母运算，直接相减更简便。
讲评提示：强调同分母分数加减法的运算顺序，以及在混合运算中保持分母不变的原则。

**q004 答案：** \frac{3}{10}
1. 将整瓶果汁看作单位 1，即 \frac{10}{10}。
2. 先计算两人一共喝了多少：\frac{3}{10} + \frac{4}{10} = \frac{7}{10}。
3. 再计算剩余部分：\frac{10}{10} - \frac{7}{10} = \frac{3}{10}。
讲评提示：引导学生理解单位 1 在分数应用题中的作用，培养分步解决问题的能力。

**q005 答案：** 对
1. 同分母分数相加，分母不变，分子相加：5 + 7 = 12。
2. 所以 \frac{5}{12} + \frac{7}{12} = \frac{12}{12} = 1。
3. 结论：该等式成立。
讲评提示：通过判断题形式，强化学生对同分母分数加法结果为 1 的特殊情况的理解，培养严谨的数学思维。
