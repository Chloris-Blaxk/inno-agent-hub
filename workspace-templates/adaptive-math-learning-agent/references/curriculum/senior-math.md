# 高中数学路由

| 领域 | 稳定概念 ID 示例 | 常见必要前置 |
| --- | --- | --- |
| 集合与函数 | `math.senior.function-domain`、`math.senior.function-properties` | 不等式、坐标、对应关系 |
| 指数对数 | `math.senior.exponential-logarithmic` | 幂、函数、定义域 |
| 三角函数 | `math.senior.trigonometry` | 单位圆、函数图像 |
| 数列 | `math.senior.sequence` | 代数式、函数关系 |
| 平面向量 | `math.senior.vector` | 坐标、几何关系 |
| 立体几何 | `math.senior.solid-geometry` | 平面几何、空间关系 |
| 解析几何 | `math.senior.analytic-geometry` | 方程、坐标、距离 |
| 概率统计 | `math.senior.probability-statistics` | 计数、事件关系 |
| 导数基础 | `math.senior.derivative-application` | 函数、变化率、代数 |

高中题尤其要检查定义域、参数范围、充要条件、分类讨论、增根漏解以及“图像直观”是否被误当作证明。
