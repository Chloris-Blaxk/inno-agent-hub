# 学术表达与保守改写规则

本文件用于把教师草稿中的教学经验表达，改写为更适合论文的学术表达。所有改写必须遵守 `conservative-editing-rules.md`：只改变表达和结构，不新增事实。

## 口语→学术表达对照表

| 口语化/经验表达 | 学术表达 | 禁止过度拔高 |
|---|---|---|
| 很多 | 大量、较多 | 不得改为"绝大多数" |
| 我觉得 | 可以认为、研究显示 | 不得改为"结果表明" |
| 所以 | 因此、由此可见 | — |
| 但是 | 然而、但 | — |
| 现在 | 当前、目前 | — |
| 越来越多 | 日益增多、呈上升趋势 | 不得改为"爆发式增长" |
| 不好 | 存在不足、有待改进 | 不得改为"严重不足" |
| 搞清楚 | 厘清、明确 | — |
| 好多同学 | 多数学生、超过半数学生 | 不得改为"全部学生" |
| 上完课感觉 | 课堂实施后观察到 | 不得改为"实验证明" |

## 教学经验→学术表达转换

| 教学经验表达 | 可改为 | 禁止改为 |
|---|---|---|
| 学生做题经常错 | 学生在该知识点学习中呈现出较集中的错误类型 | 学生错误率显著高于对照组 |
| 课堂反馈很有用 | 课堂反馈为教师调整教学提供了过程性信息 | 课堂反馈显著提升学生成绩 |
| 我发现学生不理解 | 课堂观察显示，部分学生对相关概念的理解仍不稳定 | 研究证明学生普遍缺乏该能力 |
| 讲评后效果不错 | 讲评活动后，学生在课堂表现或作业订正中出现积极变化 | 实验结果显示教学干预效果显著 |

## 强断言降级

遇到下列表述且没有证据时，必须降级：

- "显著提升""明显优于""证明""必然导致"
- "所有学生""普遍存在""完全解决"
- "实验表明""数据证明""研究发现"

降级方式：

- 把因果改为相关或支持条件：`有助于`、`可能支持`、`为……提供线索`
- 把总体改为范围表达：`部分学生`、`在本次课例中`、`从已有材料看`
- 把结论改为待验证问题：`仍需通过连续课堂观察进一步验证`

## 扩写约束

扩写只能基于已给材料和已有证据展开：

- 允许：把一句话展开为两句，补充教师材料中的具体例子
- 禁止：补造研究结果、新增数据、新增引用、改变结论边界

## 缩写约束

缩写必须保留核心要素：

- 保留：核心论点、关键证据、限定条件（范围、时间、对象）
- 可删减：冗余描述、重复举例、过渡性套话

## 输出要求

- `revisionSuggestions` 应保留原句、建议句和修改理由
- 涉及新增事实的句子，标记为 `needs_user_confirmation` 或 `needs_evidence`
- 引用插入必须来自 `source_trace` 或 `claim_support_check` 的 verified 结果
