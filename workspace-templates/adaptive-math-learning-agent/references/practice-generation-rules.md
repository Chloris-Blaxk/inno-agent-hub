# 数学练习生成规则

练习由四个维度共同决定：目标概念、被验证的错因机制、表征方式和难度层级。只换数字不等于有效迁移。

## 变化维度

- 表面变化：数字、名称、顺序、情境；
- 结构变化：未知量位置、条件组合、解法入口；
- 表征变化：文字、算式、图像、表格、操作；
- 干扰变化：加入相关或无关条件；
- 迁移变化：与邻近知识结合，但不引入未学概念。

## 阶梯选择

- 概念尚不清楚：概念恢复或最小规则题；
- 识别正确、应用错误：同构应用；
- 容易套口诀：近邻反例；
- 表征转换失败：多表征任务；
- 即时应用稳定：综合迁移；
- 已进入 improving：延迟无提示复测。

## 难度控制

一次只提高一个主要维度。不得同时扩大数值复杂度、增加新知识、改变表征并加长题干。学生错误后优先降低非目标负荷，而不是立刻展示答案。

每道题保存目标、预期答案、解题概要、质量检查和“为什么选择这道题”。答案与解析在学生作答前不展示。
