# 通用数学错因分类

先解释首个关键错误，再选择能够区分候选原因的最小探针。类型是当前证据的工作假设，不是学生标签。

| 类型 | 定义 | 典型迹象 | 优先探针 |
| --- | --- | --- | --- |
| `conceptual` | 概念边界或数学含义理解错误 | 在不同表面题中重复使用同一错误规则 | 概念辨析或近邻反例 |
| `prerequisite-gap` | 当前步骤依赖的更小知识尚不稳定 | 主方法无法开始，但简化后暴露基础缺口 | 最小前置任务 |
| `procedural` | 知道概念但步骤规则使用不完整或顺序错误 | 能口述规则但执行过程遗漏条件 | 极简同构步骤 |
| `strategy` | 方法入口或计划选择不适合当前条件 | 单步知识正确但路径无法推进 | 比较两个入口并解释选择 |
| `calculation` | 主要方法正确，局部算术或符号执行错误 | 在更简单算式中可直接复现或排除 | 去除背景的单步运算 |
| `condition-reading` | 漏读、误读或没有持续使用题目条件 | 解法对另一道近邻题成立 | 只改变一个条件的对照题 |
| `modeling` | 情境、变量和数量关系之间映射错误 | 算式内部正确但不代表题意 | 只定义变量或列关系式 |
| `representation` | 文字、符号、图、表之间转换丢失关系 | 单一表征能做，转换后失败 | 单次表征转换 |
| `reasoning` | 结论没有由已有条件充分推出 | 证明跳步、逆命题误用、以图代证 | 缺少必要条件的反例 |
| `verification` | 缺少代入、估算、单位或边界检查 | 错误结果本可由简单检查发现 | 让学生选择一种验证方法 |
| `insufficient-evidence` | 输入不足以判断具体原因 | 只有答案、图片不清或标准缺失 | 请求步骤或补充材料 |

## 归因优先级

1. 先排除题目、识别和参考标准的问题。
2. 再定位首个关键错误所在层级。
3. 候选原因最多两个，且必须能由后续探针区分。
4. 不默认使用“粗心”。只有规则探针和应用探针均正确、且没有重复模式时，才可以描述为“目前更像偶发执行失误”。
5. 后续传播错误不重复登记成多个误区。
