## 一、研究背景（评分权重 15%）

### 问题的提出

在高中英语教学中，学生的跨文化交际能力培养面临三个突出问题：

**1. 教材文化内容停留于知识层面**
现行教材中的文化内容多为"知识性介绍"（如节日、习俗等事实性知识），缺乏真实情境下的文化体验和交际实践。学生"知道"文化差异，但无法在交际场景中灵活运用。

**2. 学生存在普遍的文化误判倾向**
在跨文化案例分析教学中发现，学生最常见的误判是"用自己的文化标准评判他人"。例如在"准时观念差异"案例分析中，约 **63%** 的学生最初将"不准时"定性为"不尊重"，反映出文化自我中心倾向较为突出。

**3. PBL 与跨文化能力培养缺乏整合框架**
项目式学习（PBL）提供了一个让学生在真实任务中发展跨文化能力的平台，但如何在 PBL 中系统性地嵌入跨文化交际能力培养目标，目前缺乏成熟的操作框架。

### 研究意义

本课题响应《普通高中英语课程标准（2017 版 2020 年修订）》对文化意识素养的培养要求，尝试将 PBL 方法论与跨文化交际能力培养进行系统性融合，为高中英语文化教学从"知识传授"走向"能力培养"提供可操作的实践路径。

---

## 二、研究目标与内容（评分权重 25%）

### 研究目标

1. **构建培养框架**：构建基于 PBL 的高中英语跨文化交际能力培养框架，明确目标体系、活动设计原则和评价标准。
2. **开发评价工具**：开发并验证跨文化交际能力评价量表（含知识、态度、技能三个维度），为教学效果评估提供可靠工具。
3. **形成案例资源**：形成可推广的 PBL 教学案例集（含 4-6 个跨文化交际项目设计），覆盖不同文化主题和交际场景。
4. **验证实践效果**：通过实验班与对照班对比，验证 PBL 模式对跨文化交际能力培养的实际效果。

### 研究内容

| # | 内容 | 说明 |
|---|------|------|
| 1 | 跨文化交际能力内涵与维度梳理 | 基于课标要求和已有研究，界定本课题所培养的跨文化交际能力的内涵与构成 |
| 2 | PBL-跨文化能力整合框架设计 | 明确 PBL 各阶段（驱动问题→探究活动→成果产出→反思评价）中跨文化能力目标的嵌入方式 |
| 3 | 评价量表的开发与信效度验证 | 在现有 v1.0 量表基础上，通过两轮教学实践完成信效度检验和修订 |
| 4 | 4-6 个 PBL 跨文化交际项目设计与实施 | 覆盖时间观念、礼貌表达、教育观念、人际关系、非语言交际等文化维度 |
| 5 | 实验班 vs 对照班对比研究 | 采集前测/后测数据，分析 PBL 模式对跨文化知识、态度、技能三个维度的提升效果 |

## 三、研究方法与步骤（评分权重 20%）

### 研究方法

| 方法 | 应用场景 |
|------|---------|
| **行动研究法** | 以高二两个班为实践场域，按"计划→行动→观察→反思"循环推进 PBL 教学改进 |
| **准实验研究法** | 设置实验班与对照班，采集跨文化交际能力前测/后测数据，组间对比分析 |
| **问卷调查法** | 使用自编评价量表（三维度）+ 跨文化敏感度量表（吴老师负责）进行前后测 |
| **课堂观察法** | 使用已有课堂观察编码表，系统记录学生文化意识行为指标变化 |
| **文本分析法** | 对学生 PBL 项目作品（跨文化交际指南，平均 1200 英文词/份）进行内容分析 |
| **案例研究法** | 选取典型案例深度分析，提炼 PBL 跨文化项目的设计原则和实施策略 |
