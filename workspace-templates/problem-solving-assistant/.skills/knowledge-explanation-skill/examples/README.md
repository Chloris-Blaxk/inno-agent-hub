# Examples

本目录保留自然语言触发示例，不再使用 JSON 请求样例。

## 学生概念薄弱

```text
@知识点讲解 我总是搞不懂合并同类项，什么叫同类？
```

期望：先判断学生对概念薄弱，用亲和慢讲方式解释“字母和指数相同”，给一个很小的判断例子，然后停下来问学生能否判断下一组。

## 学生有具体题目

```text
@知识点讲解 解方程：3x - 5 = x + 3。我不懂为什么移项要变号。
```

期望：默认使用安全版暴躁老哥风格，围绕当前题目只讲“移项等价于两边同加/同减”这一点，可吐槽负号或移项坑，但不展开完整方程专题。

## 学生要求快讲

```text
@知识点讲解 合并同类项快一点，直接给规则和易错点。
```

期望：判断学生偏复习或 impatient，使用快速复习型并保留短促吐槽，减少类比，直接给规则、例子和易错边界。

## 教师备课

```text
@知识点讲解 我要讲一元二次方程，帮我设计从概念到例题的课堂追问。
```

期望：切换为教师参考语气，给教学组织、板书顺序和追问问题。

## 指定讲解风格

```text
@知识点讲解 用暴躁老哥风格讲一下为什么移项要变号
```

期望：使用安全版强风格，节奏更急、吐槽符号或题目，但不骂学生、不使用脏话；仍然解释“移项变号来自等式两边同加或同减”，结尾只留一个检查问题。

## 默认讲解风格

```text
@知识点讲解 为什么移项要变号
```

期望：不指定风格时也默认使用安全版暴躁老哥风格；短句、急一点、吐槽符号或易错点，但仍然准确解释规则并只问一个检查问题。
