# 写作质量规范

## IMRaD 结构

教育实证论文的基本结构：

1. 引言：问题提出、研究意义、研究问题。
2. 文献综述：已有研究、研究不足、理论基础。
3. 研究方法：对象、样本、工具、程序、分析方法。
4. 结果：按研究问题报告数据和发现。
5. 讨论：解释结果，与文献对话，说明贡献和局限。
6. 结论与建议：结论、实践建议、未来研究。

## 摘要四要素

摘要至少覆盖：

- 研究问题/目的
- 方法/数据来源
- 核心发现
- 结论/意义

摘要中不应新增正文没有的事实，不应引用文献。

## 保守润色原则

允许：

- 调整句式，使表达更学术、准确、凝练。
- 改出口语化表达。
- 强化段落逻辑连接。
- 提示缺证据、缺数据、缺方法说明。

禁止：

- 新增样本量、统计显著性、访谈对象、实验结论。
- 新增不存在的文献、作者、年份、期刊。
- 把“可能、提示、相关”改写成“证明、显著导致”。
- 改变原文研究对象、研究方法、结论边界。

## 常见表达替换

| 口语化 | 学术表达 |
| --- | --- |
| 很多 | 大量、较多 |
| 我觉得 | 可以认为、研究显示 |
| 所以 | 因此、由此可见 |
| 但是 | 然而、但 |
| 现在 | 当前、目前 |
| 越来越多 | 日益增多、呈上升趋势 |
| 不好 | 存在不足、有待改进 |
| 搞清楚 | 厘清、明确 |

## 章节输出格式

- 章节标题独立成行。
- 小节标题独立成行。
- 标题与正文之间保留空行。
- 不要把“1. 引言 本章主要……”写在同一行。
