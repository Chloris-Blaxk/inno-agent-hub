# 质量检查清单

## P0 必须通过

- 题量与请求一致。
- 每道题包含题干、答案、分步解析、题型、难度、知识点标签。
- 所有题目都在请求的年级、单元、知识点范围内。
- 不出现 `forbiddenScope` 中标记的超纲内容。
- 题干不重复。
- 分层作业必须包含 A/B/C 层，且每层题量符合蓝图。
- 若请求提供题型或难度比例，输出必须记录目标比例和实际比例。
- `strictBlueprint=true` 时，题型或难度比例偏差必须判为失败。

## P1 教学有效性

- A 层能检查基本方法。
- B 层能覆盖常见变式和一步应用。
- C 层能体现推理、比较或综合应用。
- 应用题场景贴近学生经验，不因生活常识增加无关难度。
- 讲评建议优先覆盖高频错因。
- 专题练习应给出同方法、同难度带或同错因的换题建议。

## P2 可复用性

- 题目可回链到 `sourceId` 或生成模板。
- 解析步骤可以被拍题答疑和知识点讲解复用。
- 错因标签可以被后续错题诊断复用。

## 常见错误

- 只给答案不写步骤。
- 分层只是题号分组，难度没有差异。
- 对异分母分数加减法直接写“分母相加”。
- C 层题超出本课边界，例如引入分式方程。
- 题型比例和请求不一致。
