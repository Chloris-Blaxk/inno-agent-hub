# 数学图像化修复

本 Skill 用于把抽象算式、错因解释或巩固题改写成更直观的可视化呈现。优先使用聊天中可稳定显示的简单图示、表格和文字标注；只有用户明确要求课堂展示页或复杂交互时，才建议另行生成 HTML 页面。

## 适用场景

- 小学低年级四则运算：用实物图标、圆点、方块、分组框、阵列图或数轴解释“合并、拿走、每组几个、平均分”。
- 分数、小数和百分数：用分数条、面积格、等分圆、数轴位置或同单位对齐图解释单位不同、通分、大小比较。
- 应用题和建模：用线段图、数量关系表、对象-数量-单位表，帮助学生看清“每份量、份数、总量”和隐藏条件。
- 几何入门：用条件标注图、对应边角表和“已知-需要-结论”链条，避免只凭图形外观下结论。
- 函数初步：用输入输出表、变化箭头、坐标点表，把解析式和图像变化联系起来。

不适用于高精度作图、复杂解析几何交互、立体几何 3D 建模或完整课堂网页。遇到这类需求，可说明应参考仓库已有的 `edu-analytic-geometry`、`edu-solid-geometry` 或 `webpage-builder` 类能力。

## 输出原则

- 图示必须服务当前错因，不为装饰而画图。
- 每轮只展示一种图示方式，避免“图、表、长解释、练习”同时堆给学生。
- 低年级优先使用具体物体语义，例如“苹果、贴纸、小棒、方块、圆点”，但保持题目数量可数、排版整齐。
- 不使用复杂符号证明替代图示；必要公式放在图示之后，作为抽象总结。
- 图示中的每个数量都要与题目一致，不能为了画得好看改变条件。
- 图示不要提前泄露巩固题答案。解释错因时可以展示订正思路；练习题阶段只展示题面和可操作图示。

## 常用图示

### 四则运算

- 加法：把两组物体并排展示，再用“合起来”连接。
- 减法：先展示总量，再划去或移走一部分。
- 乘法：用“几组，每组几个”或点阵表示。
- 除法：用“平均分成几组”或“每组几个”表示。

示例：

```text
3 组，每组 4 个：

[● ● ● ●]  [● ● ● ●]  [● ● ● ●]

3 × 4 表示 3 组 4 个，不是把 3 和 4 随便拼在一起。
```

### 分数

- 同分母：对齐相同大小的分数单位。
- 异分母：先画不同单位，再提示需要变成相同单位。
- 比大小：用等长分数条或数轴位置比较，不只看分母数字大小。

示例：

```text
1/2： [■■■■□□□□]
1/3： [■■■□□□□□□]

两条被分成的份数不同，黑色块的“单位大小”不同，所以不能直接把分母相加。
```

### 应用题

- 先列对象、每份量、份数、总量，再决定运算。
- 对“送、剩、又买、平均分”等关键词，不直接套公式，要看数量关系。

示例：

```text
每盒彩笔 8 支，买 3 盒，又送 2 支：

买的部分： [8] [8] [8]
送的部分： [2]

总量 = 3 盒的数量 + 送的 2 支
```

### 几何与函数

- 几何证明优先用“对应元素表”和“还缺什么条件”。
- 函数初步优先用输入输出表，再过渡到图像或解析式。

## 工作流程

1. 明确当前要修复的唯一错因或唯一巩固目标。
2. 根据年级和题型选择一种最轻量的图示：实物图标、点阵、数轴、分数条、线段图、表格或条件标注。
3. 先展示图示，再用一句话连接到数学语言。
4. 给出一个很小的检查问题，确认学生是否能从图示过渡到算式或规则。
5. 学生作答后再交给 `math-misconception-verifier` 或 `adaptive-math-practice` 记录证据和安排下一题。

## 边界

- 图示只是理解支架，不替代数学核验。
- 不把图形外观看成已知条件。
- 不输出大段视觉设计说明；学生只需要看到图示、关键解释和一个问题。
- 如果图示会让题目更复杂，退回更直接的文字或算式解释。
