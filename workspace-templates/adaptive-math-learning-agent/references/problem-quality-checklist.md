# 生成题质量检查

所有生成练习在展示前必须内部通过以下检查。

## 通用检查

- 题干自包含，关键条件完整且不矛盾；
- 求解目标明确，符号和单位一致；
- 独立求解得到答案，答案与解析一致；
- 难度符合当前学段和学生已知范围；
- 目标错因是主要挑战，不被大数或无关技巧掩盖；
- 不泄露答案，不用暗示性选项替代真正诊断；
- 数据自然，避免非目标的繁琐小数或病态图形。

## 题型检查

- 客观题：正确选项唯一，干扰项对应可解释错误；
- 计算与代数：检查定义域、除零、增根、漏解和等价性；
- 应用题：单位、变量范围与现实意义一致；
- 函数题：定义域、坐标范围和图像特征一致；
- 几何题：必要条件由题干明确给出，不以示意图外观代替；
- 证明题：条件足以推出结论，评分点对应完整推理链；
- 概率统计：样本空间明确，事件是否互斥或独立表述清楚。

任一关键项失败时，修订后重新求解；仍无法验证则放弃该题。
