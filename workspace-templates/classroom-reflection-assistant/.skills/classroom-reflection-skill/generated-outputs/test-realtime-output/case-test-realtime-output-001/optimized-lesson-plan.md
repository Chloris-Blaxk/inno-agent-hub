# 优化版公开课教案

生成时间：2026-06-08 19:15:00

## 一、课题名称

《紫藤萝瀑布》——从"形似"到"神似"到"物我交融"

## 二、教学对象

七年级（初中一年级）

## 三、教学目标（核心素养导向）

说明：本课依据《义务教育语文课程标准（2022年版）》确定的四个核心素养撰写目标。原"三维目标"框架已转为核心素养导向表述。

1. 通过对比紫藤萝与瀑布的外形特征，能概括二者"形似"的多个维度，并在小组讨论中用原文词句说明作者的观察角度和描写方法。
对应核心素养：语言运用（梳理与探究）

2. 通过对比当下与十多年前两株藤萝的命运变化，结合写作背景，能说出作者情感从"喜悦"到"愁思"再到"振作"的转变过程，并以口头方式条理清晰地表达。
对应核心素养：思维能力（阅读与鉴赏）

3. 通过分析"生命的长河""瀑布"两个水意象比喻，能解释作者以"瀑布"为题的三层意蕴（形似—神似—物我交融），并用一段话表达自己对"生命的长河是无止境的"的理解。
对应核心素养：审美创造、文化自信（阅读与鉴赏）

## 四、教学重点与难点

### 教学重点

通过文本细读，理解紫藤萝与瀑布从"形似"到"神似"再到"物我交融"的三层递进关系，把握作者情感变化脉络。

### 教学难点

理解"瀑布"作为核心比喻所承载的生命哲思——即作者为何将个体生命体验与"花""瀑"统一为"永恒有力的生命赞歌"。

## 五、教学思路

本课由"图片对比导入"引发学生对标题的好奇，通过"表格自主整理—小组对比阅读—古诗联读探究—写作背景推测—哲理表达"五个递进任务，引导学生经历"观察—比较—讨论—表达—归纳—迁移"的学习过程。教师从原课堂的"主讲者"转变为"追问者和点拨者"，关键结论由学生自主发现和归纳。

## 六、教学过程

| 环节 | 时间 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---:|---|
| 一、图片对比，激趣导入 | 约4分钟 | 展示紫藤萝花和瀑布两张图片，提问："你能用几个词分别描述它们的特点吗？""作者写的是一株紫藤萝，为什么标题里偏要加上'瀑布'？"板书课题和核心问题 | 观察图片，用关键词描述两者特征（如：紫藤萝—柔美、安静；瀑布—有力、流动）；记录核心探究问题 | 以直观对比激活感知，引发认知冲突——"瀑布"与"紫藤萝"的组合为什么成立？ |
| 二、表格整理，发现"形似" | 约8分钟 | 出示三列表格（紫藤萝特征 / 瀑布联想 / 原文词句证据），示范一行，要求学生在默读2-6段后独立填写；巡视个别指导；邀请2名学生上台补充板书 | 默读第2-6段；独立填写表格；小组内交换核对；代表发言分享发现 | 变教师讲述为学生自主梳理，通过表格任务驱动文本细读，发现"形似"的多维证据 |
| 三、对比阅读，走向"神似" | 约10分钟 | 出示第8段（十多年前藤萝"伶仃""稀落"）与第2-3段（当下藤萝"辉煌""闪光"）对比材料，提问："两株藤萝的命运有什么不同？""作者为什么要在写了眼前的繁盛后，又写十多年前的衰败？""作者的心情从'喜悦'转向了什么？" | 同桌合作对比两段文字，标注关键词；讨论并归纳"命运不同—生命延续—情感变化"的逻辑链；用自己的话说出作者心情变化过程 | 将原课堂教师直接讲述的内容转化为学生的对比阅读和小组讨论，培养从文本中推断作者意图的能力 |
| 四、背景推敲，理解哲思 | 约10分钟 | 先不出示背景，提问："花和人都会遇到各种各样的不幸——从这句话猜想，作者可能经历了什么不幸？"学生推测后出示写作背景（文革苦难、小弟病痛），追问："了解了背景后，再读'生命的长河是无止境的'，你有了什么新的理解？" | 基于文本线索推测作者遭遇；阅读写作背景材料；同桌讨论"为什么知道背景前和知道背景后，对这句话的感受不一样"；用关键词记录理解（如："振作""坦然""向前"） | 变背景"告知"为背景"推断—验证—深化"，让学生在主动建构中理解"物我交融"的含义 |
| 五、古诗联读，品析"水"意象 | 约7分钟 | 引导学生找到"生命的长河""瀑布"两个比喻，提问："为什么作者选水和瀑布，而不是山和塔？"提供"千古兴亡多少事？悠悠。不尽长江滚滚流。"（辛弃疾）和"大江东去，浪淘尽，千古风流人物。"（苏轼）两句，要求学生在学案上勾画关键词，找与水意象的共通点 | 找到两个比喻句；自由朗读提供的古诗词句；小组讨论水意象的共同特点（永恒、流淌、不受外物改变）；用自己的语言归纳"作者为什么以水喻生命" | 通过古诗联读拓宽理解维度，让学生体会"水"在中国文学中象征永恒的文化传统，呼应审美创造和文化自信 |
| 六、回答核心问题，形成闭环 | 约5分钟 | 回到导入时板书的核心问题："现在，你能完整说说作者为什么用'紫藤萝瀑布'做标题吗？"倾听2-3名学生回答，板书归纳三层意蕴："形似（外形相像）→ 神似（生命延续、永恒）→ 物我交融（人、花、瀑合一）" | 独立在纸上用2-3句话写下自己的理解；举手发言分享；听后补充或修正自己的回答 | 以核心问题贯穿始终，检验学生是否真正经历了从文本表层到深层哲理的理解过程 |
| 七、寄语收束，作业分层 | 约1分钟 | 以宗璞原文中的"加快脚步"收束，送出寄语；布置必做（选择文中1-2处比喻，写100字赏析）和选做（对比阅读宗璞《好一朵木槿花》或推荐阅读《丁香结》，找出相似写作手法） | 记录作业 | 分层作业兼顾巩固和拓展，呼应开头评价量表设计（学案已附评价标准） |

*注：课时约45分钟。*本教案预设为1课时完成，若课堂讨论深入可调整第五环节"古诗联读"至第二课时。"

## 七、关键问题链

| 层次 | 问题 | 目的 |
|---|---|---|
| 感知性问题 | "紫藤萝和瀑布，分别给你什么感觉？用一两个词描述。" | 激活已有经验，建立直观感受 |
| 理解性问题 | "在2-6段中，作者从哪些角度写出了紫藤萝像瀑布？你能找到几个方面的证据？" | 驱动文本细读，建构"形似"的多维认识 |
| 分析性问题 | "两株藤萝的命运有什么不同？作者为什么要写十多年前那株？" | 推动对比阅读，引导发现"生命延续"主题 |
| 分析性问题 | "花和人都会遇到各种各样的不幸——从这句话，你能猜到作者可能经历了什么吗？" | 培养从文本内部推断作者处境的能力 |
| 探究性问题 | "为什么作者偏偏选'水'来比喻生命，而不是山、火或风？古诗词中的'水'有什么共同含义？" | 通过跨文本比较，理解文化意象的深层意蕴 |
| 迁移性问题 | "现在你能完整回答：作者为什么用'紫藤萝瀑布'做标题？说说三层含义。" | 检验核心问题的理解深度，整合全课学习 |
| 反思性问题 | "学完这篇课文，如果'生命的长河是无止境的'这句话让你想起了自己或身边人的某个经历，你会想到什么？" | 连接个人经验，形成有意义的学习总结 |

## 八、课堂评价设计

| 评价时机 | 评价方式 | 评价证据 |
|---|---|---|
| 表格整理环节 | 教师巡视 + 口头反馈；学案表格完成度自检 | 学生能在表格中写出至少3处原文词句并配对藤萝和瀑布的共通特点 |
| 对比阅读环节 | 同桌互评 + 教师追问 | 学生能用"以前……现在……"的对比句式说出两株藤萝的异同 |
| 背景推敲环节 | 教师倾听学生推测 + 基于学生回答追问 | 学生能基于"花和人都会遇到各种各样的不幸"提出合理推测（如"亲人去世""生活磨难"等） |
| 核心问题回答环节 | 学生互评 + 教师归纳 | 学生能用"形似—神似—物我交融"三层结构说出标题意蕴，层级递进 |
| 作业 | 按评价量表自评 + 教师批阅 | 赏析能引用原文+解释手法+说明效果；对比阅读能找到至少1处共同写作手法 |

## 九、板书设计

```
              紫藤萝瀑布
                 宗璞

    核心问题：作者为什么以"瀑布"为题？

    形似 ───── 神似 ───── 物我交融
   （外形相像）  （生命延续·永恒）  （人 = 花 = 瀑）
    ↓            ↓              ↓
   辉煌·闪光     喜悦 → 愁思      生命的长河
   推着·挤着     稀落 → 繁盛      是无止境的
   欢笑·航行     凋零 → 绽放      加快脚步

    三层意蕴：外柔内刚 → 永恒有力的生命赞歌
```

## 十、公开课亮点说明

1. **核心问题闭环设计**：从导入到总结，始终围绕"作者为什么以'瀑布'为题"这一核心问题，确保全课不偏离主线。

2. **"背景推敲"而非"背景告知"**：写作背景采用"学生先推测—再出示验证—再回读深化"的三段策略，将传统的"教师介绍作者"转化为学生主动建构理解的过程。

3. **古诗联读支持文化理解**：不孤立分析比喻修辞，而是引入辛弃疾、苏轼诗词中的"水"意象，让学生在比较中体会中国文化中"水"象征永恒的深层逻辑，自然落实"审美创造"和"文化自信"两个核心素养。

4. **评价设计前置**：学案附有每个环节的自检评价量表，学生始终知道"学到什么程度算达标"。

5. **从"教师主讲"到"学生主学"**：原展示课全部47段为教师独白，优化后教师活动从"讲述"变为"追问+点拨+归纳"，学生活动从"听"变为"读+写+说+议"。

## 十一、相较原课堂的改进说明

| 原问题 | 改进方式 | 改进价值 |
|---|---|---|
| 全部47段转写均为教师独白，无真实学生活动 | 将表格整理、对比阅读、背景推测、古诗联读、核心问题回答全部设计为学生自主或合作任务 | 学生从"被动听"转为"主动做"，课堂有真实的读、写、说、议 |
| 写作背景由教师直接讲述 | 先让学生从"花和人都会遇到各种各样的不幸"推测作者遭遇，再出示背景验证，最后回读文本深化理解 | 培养从文本内部推断的能力，让背景知识服务于文本理解而非替代文本理解 |
| 关键结论（形似→神似→物我交融）由教师替代学生归纳 | 设计三次学生归纳机会：表格整理自主发现"形似"→对比阅读后归纳"神似"→核心问题回答时完整说出三层意蕴 | 学生经历真实的归纳和表达过程，思维发展可观察、可评价 |
| "水"意象分析以教师独白完成 | 提供两首古诗词句作为对比材料，学生小组讨论找共通点，教师仅做追问和归纳 | 从"教师告知"转为"学生发现"，同时落实文化理解（审美创造+文化自信） |
| 缺乏可操作的课堂评价 | 每环节设计明确的评价时机、方式和证据，学案附自检评价量表 | 教学评一致，教师和学生都可判断学习是否发生 |
