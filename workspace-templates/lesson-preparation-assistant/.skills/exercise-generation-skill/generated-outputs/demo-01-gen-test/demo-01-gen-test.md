## 题目

### A 层

q001. 【计算题｜难度 1】计算：\frac{4}{9} + \frac{2}{9} = ?

q002. 【应用题｜难度 2】一瓶果汁，小明喝了 \frac{1}{5}，小红喝了 \frac{2}{5}，两人一共喝了这瓶果汁的几分之几？

### B 层

q003. 【计算题｜难度 2】计算：\frac{4}{9} + \frac{2}{9} - \frac{1}{9} = ?

q004. 【应用题｜难度 3】一个水桶装满了水，第一次倒出 \frac{1}{5}，第二次倒出 \frac{2}{5}，还剩多少水？

q005. 【判断题｜难度 2】判断：\frac{3}{7} + \frac{2}{7} = \frac{5}{14} 是否正确？

## 答案与解析

### A 层

**q001 答案：** \frac{2}{3}
1. 分母相同，分数单位都是 \frac{1}{9}，直接把分子相加。
2. 4 + 2 = 6，所以 \frac{4}{9} + \frac{2}{9} = \frac{6}{9}。
3. 将 \frac{6}{9} 约分，分子分母同时除以3，得到 \frac{2}{3}。
讲评提示：强调同分母分数加法法则：分母不变，分子相加。同时提醒学生注意结果必须化为最简分数。

**q002 答案：** \frac{3}{5}
1. 求一共喝了多少，用加法：\frac{1}{5} + \frac{2}{5}。
2. 分母相同，分子相加：1 + 2 = 3，所以 \frac{1}{5} + \frac{2}{5} = \frac{3}{5}。
3. 结果 \frac{3}{5} 已经是最简分数，无需约分。
讲评提示：引导学生理解“一共”表示求和，从而选择加法运算。通过具体情境帮助学生巩固同分母分数加法的实际应用。

### B 层

**q003 答案：** \frac{5}{9}
1. 按从左到右顺序计算：\frac{4}{9} + \frac{2}{9} = \frac{6}{9}。
2. \frac{6}{9} - \frac{1}{9} = \frac{5}{9}。
3. 注意：\frac{6}{9} 可以约分为 \frac{2}{3}，但在此题中无需约分，直接计算即可。
讲评提示：强调同分母分数加减法的运算顺序，以及约分的必要性。

**q004 答案：** \frac{2}{5}
1. 把整桶水看作单位 1，即 \frac{5}{5}。
2. 第一次倒出后剩下：\frac{5}{5} - \frac{1}{5} = \frac{4}{5}。
3. 第二次倒出后剩下：\frac{4}{5} - \frac{2}{5} = \frac{2}{5}。
4. 或者直接计算总共倒出：\frac{1}{5} + \frac{2}{5} = \frac{3}{5}，然后 \frac{5}{5} - \frac{3}{5} = \frac{2}{5}。
讲评提示：引导学生理解单位 1 的概念，并掌握分步计算和整体计算两种方法。

**q005 答案：** 错误
1. 同分母分数相加，分母不变，分子相加。
2. \frac{3}{7} + \frac{2}{7} = \frac{3+2}{7} = \frac{5}{7}。
3. 题目中分母相加，是错误的。
讲评提示：强调同分母分数加减法的规则，特别是分母不变的原则，避免与异分母分数运算混淆。
