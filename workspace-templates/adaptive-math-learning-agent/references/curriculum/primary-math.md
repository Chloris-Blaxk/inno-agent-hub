# 小学数学路由

用于选择题型语言、典型前置和诊断负荷，不代表某一地区完整课程标准。

| 领域 | 稳定概念 ID 示例 | 常见必要前置 |
| --- | --- | --- |
| 整数与四则 | `math.primary.integer-operations` | 数位、运算含义 |
| 运算顺序 | `math.primary.operation-order` | 四则运算、括号含义 |
| 分数 | `math.primary.fraction-meaning`、`math.primary.fraction-operations` | 等分、倍数、通分 |
| 小数百分数 | `math.primary.decimal-percent` | 位值、分数意义 |
| 比和比例 | `math.primary.ratio-proportion` | 乘除关系、单位量 |
| 应用题 | `math.primary.word-problem-modeling` | 数量关系、单位 |
| 平面与测量 | `math.primary.measurement-geometry` | 长度、面积、角 |
| 数据 | `math.primary.data-reading` | 分类、计数、简单平均 |

小学探针应减少文字负荷和非目标计算。必要时优先使用具体数量、线段图或分割情境，但不能把画图作为所有题的固定要求。
