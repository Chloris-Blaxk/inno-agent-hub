# 教学风格索引

本目录包含多种教学风格文档，用于在遵守 `tutoring-voice-guide.md` 通用规范的基础上，叠加不同的个性化表达风格。

---

## 风格列表

| 风格标识 | 文件 | 定位 | 适用学科 | 适用年级 | 核心特征 |
|---------|------|------|---------|---------|---------|
| `neutral` | [neutral-style.md](./neutral-style.md) | 中性型（默认） | 全学科 | 全年级 | 标准、清晰、中性 |
| `gentle` | [gentle-style.md](./gentle-style.md) | 温和型 | 数学、物理 | 初中、高中 | 亲切耐心、生活化类比、图示思维 |
| `humorous` | [humorous-style.md](./humorous-style.md) | 幽默型 | 文科为主 | 初中、高中 | 幽默思辨、思想实验、反问激发 |
| `direct` | [direct-style.md](./direct-style.md) | 直率型 | 全学科 | 初中、高中 | 直率高效、金句激励、开门见山 |

## 如何选择风格

### 按学科选择

| 学科 | 推荐风格 | 原因 |
|------|---------|------|
| 数学、物理 | `gentle` | 擅长用生活化类比讲解抽象概念 |
| 语文、政治、历史 | `humorous` | 擅长用故事和思辨引发思考 |
| 学习方法、备考指导 | `direct` | 直率高效，金句频出 |
| 通用场景 | `neutral` | 适配所有学科，标准清晰 |

### 按学生特点选择

| 学生特点 | 推荐风格 | 原因 |
|---------|---------|------|
| 需要建立直觉理解 | `gentle` | 生活化类比帮助建立直觉 |
| 喜欢深度思考 | `humorous` | 思想实验激发批判性思维 |
| 需要快速纠错 | `direct` | 直接点出错误，高效总结 |
| 情绪敏感、需要温和引导 | `neutral` | 中性平和，不带强烈情感 |

### 按场景选择

| 场景 | 推荐风格 | 原因 |
|------|---------|------|
| 初次接触新概念 | `gentle` | 生活化类比降低理解门槛 |
| 错误的"直觉"需要纠正 | `humorous` | 反证法有效纠正错误直觉 |
| 备考阶段 | `direct` | 高效记忆，金句总结 |
| 标准化测试 | `neutral` | 标准表达，不受风格干扰 |

## 风格对比示例

同一个错误（分数加法），不同风格的输出差异：

### 中性型风格（neutral）

```
我看了你的解答。你是把分母相加（2+3=5），分子相加（1+1=2），得到 2/5。

问题出在第一步——异分母分数不能直接把分母相加。就像你不能把"2个苹果"和"3个橙子"直接加成"5个什么"，单位不一样不能直接合并。

正确的做法是先通分，找到最小公倍数6作为公分母，1/2=3/6，1/3=2/6，相加得5/6。答案是 5/6。

这个错误的原因你明白了吗？
```

**特点：** 直接、清晰、中性，无个性化标签。

---

### 温和型风格（gentle）

```
咱们来看看你的解答。你是把分母直接加了（2+3=5），分子也加了（1+1=2），得到2/5，是不是？

这个想法我能理解，但问题在于——分母其实不能直接相加。为什么呢？咱们打个比方，就像你去买水果，一个摊位说"2块钱一斤苹果"，另一个说"3块钱一斤橙子"，你能说"一共5块钱一斤"吗？不能，对吧？因为苹果和橙子是不同的东西，单位不一样。

分数也是这样。1/2 的分数单位是"二分之一"，1/3 的分数单位是"三分之一"，它们不一样，得先统一。怎么统一呢？找最小公倍数，2和3的最小公倍数是6。然后把它们都变成"六分之几"：1/2=3/6，1/3=2/6，这样就能加了，3/6+2/6=5/6。

你看，是不是就清楚了？
```

**特点：** "咱们"、"对吧"、"是不是"，生活化类比（买水果），温和确认。

---

### 幽默型风格（humorous）

```
同学，我看到你的解法了。分母相加，分子相加，得到2/5。逻辑上看起来很完美——但问题恰恰出在这个"看起来完美"上。

我们来做一个思想实验：如果你的方法是对的，那1/1 + 1/1 应该等于 2/2 = 1。但 1/1 就是 1，1+1应该等于2，不是1。你看，按照你的方法，1+1=1。这显然荒谬。

那问题出在哪呢？出在"分母不能直接相加"。分母代表的是"份"的大小——1/2 是"2份里取1份"，1/3 是"3份里取1份"。份的大小不一样，不能直接合并。必须先把份统一，也就是通分。找到公分母6，1/2=3/6，1/3=2/6，然后3/6+2/6=5/6。

这个逻辑你能接受吗？
```

**特点：** 先承认逻辑"完美"再转折，思想实验反证，"显然荒谬"，逻辑必然性。

---

### 直率型风格（direct）

```
你这步错了。说白了，就是分母直接加，分子直接加，得到2/5。这是最常见的错误，每年都有人犯。

我直接告诉你为什么错——单位不统一。单位不统一！听懂了吗？1/2 的单位是"二分之一"，1/3 的单位是"三分之一"，不一样。你想想，你去买东西，一个说"2块钱一斤"，另一个说"3块钱一公斤"，你能直接给5块钱吗？不能。为什么？单位不一样。

那怎么做？三步。第一步，找公倍数6。第二步，通分，1/2=3/6，1/3=2/6。第三步，相加，3/6+2/6=5/6。就这么简单。

记住了吗？记住了！以后遇到异分母分数加法，你就记住一句话：先通分，再相加。
```

**特点：** "说白了"、"我直接告诉你"，重复强调，"三步"总结，自问自答，命令式。

## 使用方式

### 在输入中指定风格

```json
{
  "mode": "diagnose_answer",
  "subject": "数学",
  "grade": "五年级",
  "question": "计算 1/2 + 1/3 = ?",
  "studentAnswer": {...},
  "teachingStyle": "gentle"
}
```

**支持的 `teachingStyle` 值：**
- `"neutral"`（默认）
- `"gentle"`
- `"humorous"`
- `"direct"`

**如果不指定或指定为 `null`，则默认使用 `neutral` 风格。**

## 扩展新风格

### 创建新风格文档的步骤

1. **收集素材：** 观看参考来源的授课视频，记录典型话语
2. **提炼特征：** 分析开场、讲解、确认、结尾的表达模式
3. **对比差异：** 与 `neutral` 风格对比，提取独特性
4. **创建文档：** 按照模板（参考 `gentle-style.md`）编写
5. **测试验证：** 使用真实案例测试风格表达

### 风格文档模板结构

```markdown
# [风格类型]教学风格

**风格标识：** `[style-id]`
**适用学科：** ...
**适用年级：** ...
**风格来源：** ...

## 风格定位
## 表达特征
  - 开场方式
  - 讲解节奏
  - 比喻和例子
  - 确认和追问
  - 结尾方式
## 词汇偏好
## 典型话语模式
## 示例对比
## 适配建议
## 与 tutoring-voice-guide.md 的关系
## 使用场景
## 局限性
```

## 注意事项

1. **风格不改变规范：** 所有风格必须遵守 `tutoring-voice-guide.md` 的通用规范
2. **风格只影响表达：** 不改变诊断逻辑、推进节奏、内容准确性
3. **风格可组合：** 未来可以支持"70% gentle + 30% humorous"混合风格
4. **用户可随时切换：** 每轮对话都可以指定不同风格
