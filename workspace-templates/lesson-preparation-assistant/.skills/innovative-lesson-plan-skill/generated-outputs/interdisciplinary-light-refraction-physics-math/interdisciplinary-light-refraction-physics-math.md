# 光的折射

## 一、基本信息

| 学科 | 物理 | 年级 | 八年级 | 课时 | 40 分钟 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **课题** | **光的折射** | **创新类型** | **跨学科融合** | **课型** | 跨学科融合课 |

## 二、双学科教材分析

### 主学科：

| 维度 | 内容 |
| :--- | :--- |
| 单元定位 | 人教版八年级上册第四章第三节——光的折射 |
| 课标要求 | 能通过实验观察光的折射现象，归纳折射规律，用折射知识解释生活现象 |

### 关联学科：

| 维度 | 内容 |
| :--- | :--- |
| 单元定位 | 人教版九年级下册第二十八章——锐角三角函数 |
| 课标要求 | 能运用三角函数解决与直角三角形有关的实际问题 |

### 课标交汇依据

物理提供光路实验数据与现象模型，数学提供正弦函数计算工具，两学科在'定量验证物理规律'层面交汇

## 三、学科关联与融合设计

### 学科关联

| 学科 | 贡献 | 课标依据 |
| :--- | :--- | :--- |
| 物理（主学科） | 提供光的折射实验情境、光路图绘制规范及折射定律的物理意义解释 | std-phy-g8-optics-001 |
| 数学（关联学科） | 提供锐角三角函数定义、计算器使用方法及数据比值计算逻辑 | std-math-g8-trig-001 |

### 融合节点

| 节点 | 描述 | 关联活动 |
| :--- | :--- | :--- |
| node-1 | 学生用数学中的正弦函数计算折射角与入射角的关系，验证斯涅尔折射定律 n1·sin(θ1) = n2·sin(θ2)，物理现象用数学公式精确描述 | act-2；act-3 |

### 共同产出

光的折射实验数据表与三角函数验证报告单

### 适用边界

适合已学锐角三角函数的八年级学生，不涉及复数、全反射临界角的复杂计算，数学以正弦函数和比例关系为主

## 四、学情分析

| 维度 | 分析 |
| :--- | :--- |
| 主学科预备水平 | 学生已学习光的直线传播和反射定律，具备基本的角度测量概念，但尚未接触折射的定量规律 |
| 关联学科预备水平 | 学生在数学课已学习锐角三角函数（正弦、余弦、正切），能使用计算器进行三角函数值计算 |
| 跨学科思维经验 | 学生较少有将数学公式直接用于验证物理定律的经验，可能存在数据记录与公式应用脱节的情况 |

## 五、核心素养目标

| 维度 | 具体表现 |
| :--- | :--- |
| 物理观念 | 形成光从一种介质斜射入另一种介质时传播方向发生改变的观念 |
| 科学思维 | 能用数学工具（三角函数）对物理实验数据进行建模与分析 |
| 探究实践 | 经历'实验测量—数据处理—规律验证'的完整探究过程 |

## 六、教学目标

| 目标 | 归属学科 | 行为动词 | 评价证据 |
| :--- | :--- | :--- | :--- |
| 通过实验观察并描述光从空气射入水中的折射现象及光路特点 | 物理 | 观察 | rubric-1 |
| 运用正弦函数计算入射角与折射角的正弦比值，验证斯涅尔折射定律 | 物理+数学 | 计算 | rubric-2 |
| 分析实验误差来源，解释折射规律在生活中的应用实例 | 物理 | 分析 | rubric-3 |

### 教学重点

利用数学正弦函数工具对物理折射实验数据进行定量处理，完成折射定律的验证

### 教学难点

实验角度测量的准确性控制以及三角函数计算过程中的有效数字处理

## 七、融合教学流程

| 环节 | 时长 | 学科归属 | 教师活动 | 学生活动 | 产出 |
| :--- | ---: | :--- | :--- | :--- | :--- |
| 情境导入与问题提出 | 5 | 物理 | 展示水中筷子弯折视频，提问：为什么看起来弯折了？；引出折射概念，明确本节课任务：寻找折射角与入射角的数量关系 | 观看视频，回忆反射定律经验；猜想入射角与折射角可能存在的比例关系 | 猜想假设记录 |
| 实验探究与数据采集 | 15 | 物理 | 分发光具盘、激光笔、半圆形水槽；指导如何准确标记入射光线和折射光线；强调量角器读数视线垂直刻度线 | 分组进行实验，改变入射角三次；记录每次的入射角θ1和折射角θ2数据；绘制光路图 | 实验原始数据记录表；光路图 |
| 数学建模与规律验证 | 15 | 学科交汇 | 提示回顾数学中正弦函数定义 sin(α)=对边/斜边；引导学生使用计算器计算 sin(θ1)/sin(θ2) 的比值；巡视指导计算器模式设置（角度制） | 调用数学知识，计算每组数据的 sin(θ1) 和 sin(θ2)；计算比值 k=sin(θ1)/sin(θ2)，观察是否为常数；对比不同组数据，归纳结论 | 三角函数计算过程草稿；验证结论陈述 |
| 总结应用与误差分析 | 5 | 物理 | 总结斯涅尔定律表达式；提问：如果比值不完全相等，原因是什么？；举例：游泳池变浅现象解释 | 汇报验证结果；讨论误差来源（如光线宽度、读数误差）；尝试用新规律解释导入环节的现象 | 误差分析报告；生活现象解释词 |

## 八、评价量规

| 维度 | 优秀 | 合格 | 待改进 | 证据来源 |
| :--- | :--- | :--- | :--- | :--- |
| 实验操作与数据记录 | 光路标记清晰，角度读数准确到度，三次数据完整无遗漏 | 光路基本正确，角度读数有轻微偏差，数据完整 | 光路混乱或角度读数错误较多，数据缺失 | 实验原始数据记录表 |
| 数学工具运用与计算 | 正确使用计算器正弦功能，比值计算准确，能发现近似常数规律 | 能进行正弦计算，比值存在一定波动但能得出大致结论 | 计算器使用错误或无法建立角度与正弦值的联系 | 三角函数计算过程草稿 |
| 规律解释与反思 | 能准确表述折射定律，深入分析误差来源并给出合理建议 | 能表述定律，简单提及误差但未深入分析 | 无法表述定律或归因错误 | 误差分析报告 |

## 十、教学反思要点

- 融合节点是否是完成核心任务的必要环节？（去掉关联学科后核心任务能否完成）
- 两个学科的知识是否在融合节点自然交汇？（还是简单的前半节A后半节B）
- 共同产出是否真正融合了两学科的方法和成果？（还是两学科产出的简单拼接）
