# 初中数学路由

| 领域 | 稳定概念 ID 示例 | 常见必要前置 |
| --- | --- | --- |
| 有理数与代数式 | `math.junior.algebraic-expressions` | 符号、运算顺序 |
| 方程不等式 | `math.junior.equation-equivalence` | 逆运算、等式性质 |
| 函数 | `math.junior.function-correspondence` | 变量、坐标、比例关系 |
| 三角形与全等 | `math.junior.triangle-congruence` | 角、边、对应关系 |
| 平行与相似 | `math.junior.similarity` | 比例、角关系 |
| 圆 | `math.junior.circle-properties` | 角、垂直、相似 |
| 概率统计 | `math.junior.probability-statistics` | 比例、计数、平均数 |
| 应用建模 | `math.junior.modeling` | 变量定义、数量关系 |

判断前置缺口时只追溯完成当前步骤真正需要的概念，最多三个。不能因为 L1 没有记录就假定学生不会。
