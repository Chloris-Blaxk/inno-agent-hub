# 备课助手智能体

## 智能体简介

备课助手是一个专为K-12和大学教师设计的AI助手，通过统一的对话入口解决备课工作中最耗时的三大核心任务：出题、课件制作和教案编写。

**核心特点：**
- **智能路由**：理解教师的自然语言需求，自动调用相应的专业技能模块
- **联动工作流**：支持跨技能协同，一次对话完成教案→课件→练习的完整备课链路
- **灵活适配**：支持K-12各学段和大学教学场景，根据需求自动调整难度和风格

## 核心能力

### 1. 智能出题

**功能描述：**
根据教学内容、难度要求和题型需求，自动生成各类练习题和测试卷。

**支持的题目类型：**
- **课堂练习题**：即时反馈类题目，用于课堂教学过程中的知识巩固
- **分层作业题**：根据学生水平差异，生成基础、提高、拓展三个层次的作业
- **单元测试卷**：覆盖单元知识点的综合性测试，包含选择、填空、简答、应用等多种题型
- **期中/期末考试卷**：符合课程标准的综合性考试试卷，含试题、参考答案和评分标准
- **专题练习**：针对特定知识点或题型的集中训练

**生成机制：**
- **种子库模式**（默认）：毫秒级响应，从结构化题库中选题和变式，结果可复现
- **动态生成模式**：调用大模型生成新题，每层15-30秒，适用于题库未覆盖的知识点

**输出内容：**
- 题干、答案、分步解析
- 知识点标注、题型分类、难度标签
- 常见错因和讲评建议
- 覆盖报告、难度报告、风险报告
- 换题建议（相似题推荐）

**默认输出格式：** Markdown（教师可读版 + JSON结构化数据）

### 2. 课件生成

**功能描述：**
根据教学内容和教学设计，自动生成结构清晰、内容丰富、投影友好的课件。

**生成流程（三阶段）：**
1. **设计阶段**：生成教学设计稿，确认课堂目标、页面规划、教学节奏
2. **脚本阶段**：生成教师逐字稿、学生屏幕内容、追问和备注
3. **渲染阶段**：生成可编辑PPTX和HTML预览

**生成内容包括：**
- **课程导入页**：引入情境、问题或案例
- **知识点讲解页**：结构化呈现核心概念和原理
- **例题演示页**：配合讲解的典型例题
- **练习互动页**：课堂练习和互动环节设计
- **总结回顾页**：知识点梳理和思维导图
- **教师备注**：每页的逐字稿、追问建议、反馈证据、时间分配

**设计特点：**
- 投影友好的ED固定版式（ED01-ED12）
- 自动生成教师逐字稿和课堂反馈证据
- 页数和节奏根据学段自动调整（小学低段8-10页，高中理科12-14页）
- 支持插入图表、图片等多媒体元素（提供占位和生成提示）

**默认输出格式：** PPTX（可编辑）+ HTML预览 + Markdown教师脚本

### 3. 教案生成

**功能描述：**
生成符合教育教学规范的各类教案，支持传统教案和创新教案两大类型。

**传统教案：**
- 标准课时教案：包含教学目标、教学重难点、教学过程、板书设计等完整要素
- 单元教学设计：整体规划单元教学的目标、内容和评价
- 大单元设计：跨课时、跨章节的主题式教学设计

**创新教案（三大类型）：**

1. **项目式学习（PBL）**：设计真实情境下的探究性学习项目
   - 驱动问题设计
   - 项目里程碑和阶段产出
   - 过程评价和作品评价量规
   - 支持单课时项目或跨课时项目

2. **跨学科融合**：打破学科边界的主题式教学
   - 识别主学科和关联学科的真实融合节点
   - 设计需要多学科知识共同完成的任务
   - 明确适用边界和共同产出
   - 避免简单的"标签并列"

3. **AI融合课堂**：将人工智能技术或AI主题融入学科教学
   - 明确AI工具角色和介入环节
   - 设计人机协同流程
   - 包含学生审辨任务（避免炫技）
   - 划定AI使用边界和风险提示

**生成机制（两阶段）：**
1. **需求明确阶段**：智能体通过对话引导，明确创新类型和专属上下文
2. **生成执行阶段**：调用大模型生成结构化教案，并导出为Word格式

**输出内容：**
- 教学背景分析、学情分析
- 核心素养、教学目标、教学重难点
- 创新设计说明（类型专属）
- 活动流程（包含时间分配、支架设计）
- 评价量规（过程评价+成果评价）
- 教学资源清单

**默认输出格式：** DOCX（Word标准教案格式）+ JSON结构化数据

## 智能体架构

### 技能模块集成

备课助手整合了三个专业技能模块，通过智能路由自动调用：

| 技能模块 | 入口Token | 调用时机 | 技能路径 |
|---------|----------|---------|---------|
| **出题技能** | `@出题` | 用户需要生成练习、作业、测试卷 | `.skills/exercise-generation-skill` |
| **课件生成技能** | `@课件生成` | 用户需要生成PPT课件或教学脚本 | `.skills/lesson-deck-generation-skill` |
| **创新教案技能** | `@创新教案生成` | 用户需要生成创新类型教案 | `.skills/innovative-lesson-plan-skill` |

### 工作模式

#### 模式一：单技能调用（独立任务）

用户明确指定单一任务时，智能体直接路由到对应技能：

```
用户："帮我出一套五年级数学分数加减法的分层作业"
智能体：
  1. 识别任务类型 → 出题
  2. 抽取参数：学科=数学，年级=五年级，知识点=分数加减法，任务类型=分层作业
  3. 调用 @出题 技能
  4. 返回结果：分层作业题（A/B/C三层）+ 答案解析 + Markdown
```

```
用户："生成一份高中物理'牛顿第二定律'的课件"
智能体：
  1. 识别任务类型 → 课件
  2. 抽取参数：学科=物理，年级=高中，课题=牛顿第二定律
  3. 调用 @课件生成 技能（三阶段）
  4. 返回结果：PPTX + HTML预览 + 教师脚本
```

#### 模式二：联动工作流（组合任务）

用户需要完整备课资源时，智能体自动编排跨技能工作流：

**场景1：创新教案 → 课件 → 练习**
```
用户："帮我准备一节AI融合的初中数学'一元一次方程'课"
智能体：
  1. 识别联动需求 → 创新教案 + 课件 + 练习
  2. 阶段一：调用 @创新教案生成
     - 引导确认创新类型（AI融合）
     - 明确AI工具介入环节和使用边界
     - 生成AI融合教案.docx
  3. 阶段二：调用 @课件生成
     - 传递handoff：教学目标、活动流程、评价量规
     - 生成课件.pptx
  4. 阶段三：调用 @出题
     - 生成配套练习题.md
  5. 汇总输出：教案 + 课件 + 练习（完整备课包）
```

**场景2：课件 → 练习**
```
用户："生成一份'光合作用'的课件，并配上课堂练习"
智能体：
  1. 阶段一：调用 @课件生成 → 生成课件.pptx
  2. 阶段二：调用 @出题
     - 传递handoff：知识点、难度、练习建议
     - 生成课堂练习.md
  3. 汇总输出：课件 + 练习
```

### 参数自动抽取与交互式补全

**共同必填参数：**
- `subject`（学科）
- `grade`（年级/学段）
- `topic`（课题）

**技能特定参数：**

| 参数 | 出题需要 | 课件需要 | 教案需要 | 处理策略 |
|-----|---------|---------|---------|---------|
| `knowledgePointIds` | ✓ | - | - | 自动从课题映射，失败则追问 |
| `taskType` | ✓ | - | - | 从用户需求推断（分层作业/单元测试等） |
| `lessonType` | - | ✓ | - | 默认`new_concept`，可从课题推断 |
| `durationMin` | - | ✓ | ✓ | 默认40分钟，影响页数和活动时长 |
| `innovationType` | - | - | ✓ | 必须明确（PBL/跨学科/AI融合），通过引导确认 |
| `textbookVersion` | 可选 | 可选 | 可选 | 用户指定则使用，否则不假设教材版本 |
| `layers` | 可选 | - | - | 分层作业默认A/B/C，用户可自定义 |
| `questionCount` | 可选 | - | - | 根据任务类型使用默认值 |
| `difficultyRange` | 可选 | - | - | 未指定时询问用户或使用学段默认值 |

**抽取策略：**
1. **优先推断**：从用户输入中推断参数（如"分层作业"→`taskType=layered_homework`）
2. **智能默认**：使用学段和任务类型的合理默认值
3. **必要追问**：关键参数缺失且无法推断时，反问用户（简短、精准）

## 使用方式

### 快速开始

**出题任务：**
```
"请为高中数学必修一'集合'这一节生成一套课堂练习题，包含10道选择题和5道填空题，难度中等"

"帮我出一套初中英语定语从句的分层作业，A层基础题，B层提高题，C层拓展题"

"生成一份七年级数学'一元一次方程'单元测试卷，包含答案和解析"
```

**课件生成任务：**
```
"请为初中物理'光的反射'这一课生成一份完整的PPT课件，包含实验演示和互动环节"

"生成大学《数据结构》课程'二叉树遍历'章节的课件"

"帮我做一个小学三年级语文《荷花》的课件，要有图片和朗读指导"
```

**教案编写任务：**
```
"请为小学语文五年级设计一份'走进春天'主题的跨学科教案，融合语文、科学和美术"

"帮我写一个初中地理'气候类型'的项目式学习教案，学生最终产出一份城市气候分析报告"

"设计一节AI融合的高中历史课，主题是'工业革命'，让学生用AI工具分析历史数据"
```

**联动任务：**
```
"帮我准备一节完整的初二物理'浮力'课，需要教案、课件和练习题"

"我要上一节PBL课，主题是'校园节水方案'，帮我生成教案和配套课件"
```

### 学段适配

智能体根据学段自动调整生成策略：

| 学段 | 课件页数 | 题目语言 | 活动复杂度 | 评价方式 |
|-----|---------|---------|-----------|---------|
| **小学低段（1-3年级）** | 8-10页 | 简洁、口语化 | 游戏化、具象操作 | 过程鼓励为主 |
| **小学高段（4-6年级）** | 10-12页 | 清晰、有逻辑连接词 | 小组合作、初步探究 | 过程+结果 |
| **初中** | 10-14页 | 规范、有学科术语 | 深度探究、跨学科连接 | 量规化评价 |
| **高中** | 12-14页 | 精准、抽象思维 | 复杂问题解决、学术规范 | 分层+创新评价 |
| **大学** | 15-20页 | 学术化、专业术语 | 研究性、前沿探索 | 学术标准评价 |

**学段相关参数未明确时，智能体会反问确认：**
```
智能体："请问这是面向哪个年级的学生？（如：五年级、初二、高一）"
智能体："这道题的难度需要基础、中等还是拓展？"
```

## 输出产物说明

### 文件组织结构

每次生成任务会在工作目录下创建独立的输出文件夹：

```
generated-outputs/
├── <任务名称>/
│   ├── <任务名称>.json          # 结构化数据（所有任务）
│   ├── <任务名称>.md            # 教师可读版（出题、课件脚本）
│   ├── <任务名称>.pptx          # 可编辑课件（课件任务）
│   ├── <任务名称>.html          # HTML预览（课件任务）
│   ├── <任务名称>.docx          # Word教案（教案任务）
│   ├── <任务名称>.design.json   # 设计稿（课件阶段一）
│   └── <任务名称>.design.md     # 设计稿说明（课件阶段一）
```

### 输出格式配置

**默认格式：**
- 出题：Markdown（`.md`）+ JSON
- 课件：PPTX（`.pptx`）+ HTML预览 + Markdown脚本
- 教案：DOCX（`.docx`）+ JSON

**自定义格式：**
用户可在请求中指定输出格式，例如：
```
"生成课件，只要HTML预览，不需要PPTX"
"出题只要JSON数据，不需要Markdown"
```

### 产物内容说明

**出题产物包含：**
- 题目集（按层级/题型组织）
- 答案解析（分步骤、含错因）
- 覆盖报告（知识点覆盖情况）
- 难度报告（题目分布统计）
- 风险报告（重复题、超纲风险）
- 换题建议（相似题推荐）

**课件产物包含：**
- 课件元数据（学科、年级、课题、课型、时长）
- 教学设计稿（阶段一，含页面规划和节奏）
- 完整课件（阶段二，含逐字稿和学生屏幕）
- HTML预览（横向全屏，投影友好）
- PPTX文件（可编辑，保留对象和备注）
- 质量报告（结构校验、时长偏差、版式检查）

**教案产物包含：**
- 教学背景和学情分析
- 教学目标（知识与技能、过程与方法、情感态度价值观）
- 教学重难点
- 创新设计说明（类型专属）
- 活动流程（详细到每个环节的时间、目标、活动、支架、评价）
- 评价量规（过程评价+成果评价）
- 板书设计、教学资源清单

## 质量保证机制

### 自动校验流程

每个技能模块生成后，智能体会自动运行质量校验：

**出题校验：**
- ✓ 题量、分层、题型比例是否符合要求
- ✓ 每道题是否包含答案、解析、知识点
- ✓ 题干是否重复
- ✓ 是否存在超纲风险
- ✓ 分层作业是否区分A/B/C层

**课件校验：**
- ✓ JSON结构完整性（必填字段检查）
- ✓ 页面版式是否符合ED固定版式规范
- ✓ 总时长与设定课时长度偏差是否<10%
- ✓ 教师逐字稿是否泄漏到学生屏幕
- ✓ 练习和互动是否有可收集的反馈证据
- ✓ HTML渲染是否符合投影友好规则

**教案校验：**
- ✓ 教学目标、活动流程、评价量规是否对齐
- ✓ 行为动词是否符合认知层次
- ✓ 活动总时长是否等于设定课时长度
- ✓ 创新类型专属字段是否完整（如PBL必须有驱动问题）
- ✓ 教学重点是否对齐主目标
- ✓ 教学难点是否在流程中有支架设计

### 错误处理策略

**校验通过：** 直接返回结果和输出路径

**校验警告（Warnings）：** 返回结果 + 提示改进建议
```
智能体："课件已生成，但有以下建议：
- 总时长43分钟，略超课时设定（40分钟），建议压缩'例题演示'环节
- 第5页练习题未设置反馈证据，建议补充"
```

**校验失败（Failed）：** 自动修复或重新生成
```
智能体："检测到结构问题，正在自动修复...（已完成）
课件已生成：math-g5-fraction-addition.pptx"
```

**无法修复：** 降级报告用户
```
智能体："生成失败：当前题库未覆盖'大学微积分-多元函数极值'知识点。
建议：
1. 切换为动态生成模式（预计90秒）
2. 手动补充种子题库"
```

### 迭代优化

用户可基于生成结果提出修改要求：
```
用户："课件第3页的例题太难了，换一个简单的"
智能体：调用课件技能修改特定页面 → 返回更新后的PPTX

用户："分层作业的C层题目再增加2道"
智能体：调用出题技能补充 → 返回更新后的作业.md
```

## 性能预期

| 任务类型 | 预计时间 | 说明 |
|---------|---------|------|
| **出题（种子库模式）** | <1秒 | 从结构化题库选题和变式，毫秒级响应 |
| **出题（动态生成）** | 15-30秒/层 | 调用大模型生成新题，适用于题库未覆盖的知识点 |
| **课件（阶段一：设计稿）** | 20-40秒 | 生成教学设计和页面规划 |
| **课件（阶段二：逐字稿）** | 40-90秒 | 生成完整课件JSON和教师脚本 |
| **课件（阶段三：渲染）** | 5-10秒 | 渲染HTML和导出PPTX（本地处理） |
| **教案（需求明确）** | 30-60秒 | 交互式澄清创新类型和专属上下文 |
| **教案（生成执行）** | 60-120秒 | 生成完整教案JSON和导出DOCX |
| **联动工作流** | 2-5分钟 | 多技能串联，取决于任务组合 |

**推荐使用模式：**
- **日常备课**：单技能调用，快速生成单项资源
- **公开课准备**：联动工作流，生成完整备课包
- **临时补充**：出题（种子库模式），秒级响应

## 技术特点

- **智能理解**：准确理解教学目标和课程标准要求，支持K-12和大学多学段
- **内容专业**：生成内容符合学科知识规范和教学规律
- **格式规范**：输出符合教育行业标准格式（PPTX、DOCX、Markdown）
- **灵活可调**：支持多种参数和选项的自定义配置

## 注意事项

1. **生成内容仅供参考**：教师应根据实际情况进行调整和个性化修改
2. **保护学生隐私**：涉及具体学生信息时，注意保护学生隐私
3. **教材版本**：如需对齐特定教材版本，请在请求中明确指定
4. **创新教案可行性**：创新教案需要根据学校实际条件和资源进行可行性评估
5. **难度适配**：如对学段难度有特殊要求，请在请求中明确说明
6. **数据覆盖**：部分学科和知识点的题库可能覆盖不足，建议使用动态生成模式或补充种子题库
7. **质量反馈**：如生成结果不符合预期，可提出修改要求进行迭代优化
