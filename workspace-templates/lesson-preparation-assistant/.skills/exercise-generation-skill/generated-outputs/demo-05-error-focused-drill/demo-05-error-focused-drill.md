## 题目

q001. 【计算题｜难度 1】计算：\frac{1}{3} + \frac{1}{5} = ?

q002. 【应用题｜难度 2】小明喝了一杯牛奶的\frac{1}{4}，小红喝了同一杯牛奶的\frac{2}{5}。两人一共喝了这杯牛奶的几分之几？

q003. 【计算题｜难度 2】计算：\frac{7}{8} - \frac{2}{5} = ?

q005. 【判断题｜难度 2】判断：\frac{3}{4} + \frac{1}{6} = \frac{4}{10} = \frac{2}{5}。这个计算过程对吗？为什么？

q008. 【应用题｜难度 4】一个工程队修一条路，第一天修了全长的 \frac{1}{3}，第二天修了全长的 \frac{2}{5}，第三天修了全长的 \frac{1}{6}。三天一共修了全长的几分之几？还剩几分之几没有修？

## 答案与解析

### A 层

**q001 答案：** \frac{8}{15}
1. 找到分母3和5的最小公倍数，即15。
2. 将\frac{1}{3}通分为\frac{5}{15}，将\frac{1}{5}通分为\frac{3}{15}。
3. 同分母分数相加：\frac{5}{15} + \frac{3}{15} = \frac{8}{15}。
讲评提示：强调通分是异分母分数加减法的关键步骤，需先统一单位再计算。

**q002 答案：** \frac{13}{20}
1. 求一共喝了多少，用加法：\frac{1}{4} + \frac{2}{5}。
2. 找到分母4和5的最小公倍数，即20。
3. 将\frac{1}{4}通分为\frac{5}{20}，将\frac{2}{5}通分为\frac{8}{20}。
4. 同分母分数相加：\frac{5}{20} + \frac{8}{20} = \frac{13}{20}。
讲评提示：引导学生理解‘一共’对应加法运算，并注意通分后的计算准确性。

### B 层

**q003 答案：** \frac{19}{40}
1. 找到8和5的最小公倍数，即40。
2. 将\frac{7}{8}通分为\frac{35}{40}，将\frac{2}{5}通分为\frac{16}{40}。
3. 进行减法运算：\frac{35}{40} - \frac{16}{40} = \frac{19}{40}。
讲评提示：强调通分的必要性，提醒学生通分时分子和分母要乘以相同的数。

**q004 答案：** 小红喝得多，多\frac{1}{15}。
1. 比较\frac{1}{3}和\frac{2}{5}的大小，需要先通分。
2. 3和5的最小公倍数是15，\frac{1}{3} = \frac{5}{15}，\frac{2}{5} = \frac{6}{15}。
3. 因为\frac{6}{15} > \frac{5}{15}，所以小红喝得多。
4. 计算多多少：\frac{6}{15} - \frac{5}{15} = \frac{1}{15}。
讲评提示：引导学生理解比较分数大小需要先通分，再比较分子的大小。

**q005 答案：** 不对。正确计算应为\frac{11}{12}。
1. 指出错误：不能直接将分子和分母分别相加。
2. 正确计算：4和6的最小公倍数是12，\frac{3}{4} = \frac{9}{12}，\frac{1}{6} = \frac{2}{12}。
3. 相加：\frac{9}{12} + \frac{2}{12} = \frac{11}{12}。
讲评提示：强调异分母分数加减法必须先通分，不能直接加减分子和分母。

### C 层

**q006 答案：** \frac{11}{24}
1. 8、3、6的最小公分母是24。
2. \frac{7}{8} = \frac{21}{24}，\frac{2}{3} = \frac{16}{24}，\frac{1}{6} = \frac{4}{24}。
3. 21/24 - 16/24 + 4/24 = 9/24 = 11/24。
讲评提示：强调多步运算时要统一通分，注意运算顺序，结果要约分。

**q007 答案：** 正确。\frac{3}{4} + \frac{1}{5} = \frac{19}{20}，而 \frac{3}{4} = \frac{15}{20}，\frac{4}{5} = \frac{16}{20}，所以 \frac{15}{20} < \frac{19}{20} < \frac{16}{20} 不成立，但 \frac{3}{4} < \frac{19}{20} 成立，且 \frac{19}{20} > \frac{4}{5}，所以原说法错误。
1. 计算 \frac{3}{4} + \frac{1}{5} = \frac{15}{20} + \frac{4}{20} = \frac{19}{20}。
2. 比较 \frac{19}{20} 和 \frac{3}{4}：\frac{3}{4} = \frac{15}{20}，所以 \frac{19}{20} > \frac{15}{20}。
3. 比较 \frac{19}{20} 和 \frac{4}{5}：\frac{4}{5} = \frac{16}{20}，所以 \frac{19}{20} > \frac{16}{20}。
4. 因此，\frac{3}{4} + \frac{1}{5} 比 \frac{3}{4} 大，但比 \frac{4}{5} 大，所以小明的说法错误。
讲评提示：引导学生理解分数加法的意义，以及分数大小比较的方法，特别是通分比较。

**q008 答案：** 三天一共修了 \frac{9}{10}，还剩 \frac{1}{10} 没有修。
1. 求三天一共修了多少：\frac{1}{3} + \frac{2}{5} + \frac{1}{6}。
2. 3、5、6的最小公分母是30。
3. \frac{1}{3} = \frac{10}{30}，\frac{2}{5} = \frac{12}{30}，\frac{1}{6} = \frac{5}{30}。
4. 10/30 + 12/30 + 5/30 = 27/30 = 9/10。
5. 求还剩多少：1 - \frac{9}{10} = \frac{1}{10}。
讲评提示：强调多步应用题的解题步骤，先求和再求差，注意单位‘1’的运用。
