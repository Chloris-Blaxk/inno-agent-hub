## 答案与解析

### A 层

**q001 答案：** 1/2
1. 把 2/5 通分为 4/10。
2. 4/10 + 1/10 = 5/10。
3. 5/10 约分为 1/2。
讲评提示：这题用于检查学生是否有化简意识。

**q002 答案：** 1/2
1. 1/3 = 2/6。
2. 5/6 - 2/6 = 3/6。
3. 3/6 约分，得 1/2。
讲评提示：提醒学生最后检查能否约分。

**q003 答案：** 5/6
1. 把 1/2 通分为 3/6，把 1/3 通分为 2/6。
2. 同分母分数相加，3/6 + 2/6 = 5/6。
讲评提示：重点追问为什么不能写成 2/5。

### B 层

**q004 答案：** 一共耕了 5/8，还剩 3/8。
1. 先求一共耕了多少：3/8 + 1/4。
2. 1/4 = 2/8，所以 3/8 + 2/8 = 5/8。
3. 再求剩下：1 - 5/8 = 3/8。
讲评提示：这是一步加法加一步补全整体的综合题。

**q005 答案：** 1又1/24
1. 3 和 8 的公分母可以取 24。
2. 2/3 = 16/24，3/8 = 9/24。
3. 16/24 + 9/24 = 25/24 = 1又1/24。
讲评提示：提醒学生结果大于 1 时要会解释数量意义。

**q006 答案：** 13/20
1. 求一共吃了多少，用加法：2/5 + 1/4。
2. 2/5 = 8/20，1/4 = 5/20。
3. 8/20 + 5/20 = 13/20。
讲评提示：让学生圈出关键词一共。

**q007 答案：** 7/12
1. 6 和 4 的公分母可以取 12。
2. 5/6 = 10/12，1/4 = 3/12。
3. 10/12 - 3/12 = 7/12。
讲评提示：适合讲评分子随分母变化的原因。

### C 层

**q008 答案：** 2/3 + 1/4 更大，大 1/12。
1. 计算 2/3 + 1/4：2/3 = 8/12，1/4 = 3/12，8/12 + 3/12 = 11/12。
2. 5/6 = 10/12。
3. 11/12 > 10/12，相差 1/12。
讲评提示：让学生先估计再精确计算。

**q009 答案：** 不对。一天共用去 17/30，比 1/2 多 1/15。
1. 先求一天共用去多少：2/5 + 1/6。
2. 通分为 12/30 + 5/30 = 17/30。
3. 1/2 = 15/30，17/30 > 15/30，所以超过半桶。
4. 17/30 - 15/30 = 2/30 = 1/15。
讲评提示：鼓励学生用比较而不是只给计算结果。

**q010 答案：** 5/4
1. 4、6、3 的公分母可以取 12。
2. 3/4 = 9/12，5/6 = 10/12，1/3 = 4/12。
3. 9/12 + 10/12 - 4/12 = 15/12 = 5/4。
讲评提示：用于检查学生能否把方法迁移到三个分数。
