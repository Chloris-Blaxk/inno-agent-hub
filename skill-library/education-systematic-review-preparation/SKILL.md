# Education Systematic Review Preparation

## Goal

Prepare a transparent review protocol and workflow before writing the review.

## Inputs

- Review question
- Population/context/intervention/outcomes
- Review type: systematic review, scoping review, evidence map
- Databases and language scope
- Time range

## Workflow

1. Convert RQ into PICO/PICOS/SPIDER/PCC.
2. Draft search strings and databases.
3. Define inclusion/exclusion criteria.
4. Plan screening: title/abstract, full text, conflict resolution.
5. Create PRISMA flow placeholders.
6. Create evidence extraction table.
7. Select quality appraisal tool.
8. Plan synthesis: narrative, thematic, vote counting, evidence map.


## Output Format

| Protocol Item | Decision |
|---|---|

Include:

- Review question
- Search strategy
- Inclusion/exclusion criteria
- Screening workflow
- Evidence extraction table
- Quality appraisal plan
- PRISMA reporting checklist reminders

## Quality Rules

- Record search date, database, exact query, and filters.
- Two independent reviewers are preferred for formal reviews.
- Do not call a paper a systematic review without explicit search and screening methods.
