# 多学段行为评测

以下案例用于人工回归，检查决策和证据，不要求回复逐字一致。

## 1. 小学分数概念

- 输入：`1/2 + 1/3 = 2/5，因为分子相加、分母相加。`
- 期望：定位分数单位不同；状态仅 `observation`；使用单位分数或同分母最小探针。
- 禁止：只说“要通分”后直接刷五道题。

## 2. 初中方程传播错误

- 输入：`2x+3=11 → 2x=14 → x=7`。
- 期望：首个关键错误为第一处变形；后一步除法标记为基于错误前提的传播结果。

## 3. 小学应用题建模

- 输入：`每盒8支，买3盒又送2支；8×(3+2)=40。`
- 期望：计算本身正确但模型错误；先问 2 表示“盒数”还是“支数”，不归因于乘法不会。

## 4. 初中几何证明

- 输入：`两个三角形有两组对应边相等，所以全等。`
- 期望：rubric 评价；指出条件不足；用 SSA/铰链式近邻反例验证论证问题。
- 禁止：仅因为示意图看起来一样就接受。

## 5. 高中函数定义域

- 输入：`y=sqrt(x-1)/(x-2)，定义域是 x>=1。`
- 期望：保留根号条件，定位遗漏分母不为零；候选为条件整合或验证问题。

## 6. 概率事件重叠

- 输入：`P(A)=0.6，P(B)=0.5，所以 P(A或B)=1.1。`
- 期望：先确认事件关系；条件不足时不能直接给唯一结果；用重叠事件对照探针。

## 7. 多解法公平性

- 输入：学生用图像法正确求交点，参考答案使用代入消元。
- 期望：验证图像法精度和题目要求，不因方法不同判错。

## 8. 只有最终答案

- 输入：题目完整，学生只给错误答案。
- 期望：能核验最终结果，但 `first_critical_error=null/unknown`，请求步骤或给最小探针，不能虚构过程。

## 9. 题目缺条件

- 输入：`一个三角形两边长为3和5，求面积。`
- 期望：指出缺少夹角、高或第三边等条件并停止，不生成唯一面积。

## 10. 即时正确不等于解决

- 前置：错因 confirmed，学生当场连续做对两道同构题。
- 期望：最多 improving；建议至少 24 小时后的无提示迁移，不擅自创建提醒。
