## 答案与解析

### A 层

**q001 答案：** \frac{6}{9}
1. 分母相同，分数单位都是 \frac{1}{9}，直接把分子相加。
2. 4 + 2 = 6，所以 \frac{4}{9} + \frac{2}{9} = \frac{6}{9}。
讲评提示：强调同分母分数加法的本质是分数单位的累加，分母不变。

**q002 答案：** \frac{3}{5}
1. 求一共喝了多少，用加法：\frac{1}{5} + \frac{2}{5}。
2. 分母相同，分子相加：1 + 2 = 3，得 \frac{3}{5}。
讲评提示：引导学生将生活情境转化为数学问题，理解“一共”对应加法运算。

**q003 答案：** \frac{4}{10}
1. 分母相同，分数单位都是 \frac{1}{10}，直接把分子相减。
2. 7 - 3 = 4，所以 \frac{7}{10} - \frac{3}{10} = \frac{4}{10}。
讲评提示：强调同分母分数减法的本质是分数单位的减少，分母不变。

### B 层

**q004 答案：** \frac{2}{3}
1. 分母相同，分数单位都是 \frac{1}{9}，按从左到右顺序计算。
2. 先算 \frac{5}{9} + \frac{2}{9} = \frac{7}{9}。
3. 再算 \frac{7}{9} - \frac{1}{9} = \frac{6}{9}。
4. \frac{6}{9} 约分，分子分母同时除以3，得 \frac{2}{3}。
讲评提示：强调同分母分数加减法的运算顺序和结果必须化为最简分数。

**q005 答案：** \frac{13}{20}
1. 求一共喝了多少，用加法：\frac{1}{4} + \frac{2}{5}。
2. 分母不同，需要先通分。4和5的最小公倍数是20。
3. 将 \frac{1}{4} 化为 \frac{5}{20}，将 \frac{2}{5} 化为 \frac{8}{20}。
4. 相加：\frac{5}{20} + \frac{8}{20} = \frac{13}{20}。
讲评提示：通过具体情境帮助学生理解异分母分数加法需要先通分，强调通分时分子分母要同乘一个数。

**q006 答案：** \frac{3}{8}
1. 方法一：先算一共用去多少：\frac{3}{8} + \frac{1}{8} = \frac{4}{8} = \frac{1}{2} 米。
2. 再算还剩多少：\frac{7}{8} - \frac{1}{2} = \frac{7}{8} - \frac{4}{8} = \frac{3}{8} 米。
3. 方法二：连续减去两次用去的：\frac{7}{8} - \frac{3}{8} - \frac{1}{8} = \frac{4}{8} - \frac{1}{8} = \frac{3}{8} 米。
讲评提示：引导学生理解“连续减去”和“先求和再减去”两种思路，培养灵活解题的能力。

### C 层

**q007 答案：** 1
1. 将喝掉的部分和剩下的部分相加，得到原来的总量。
2. 喝掉的部分：\frac{2}{5} + \frac{1}{5} = \frac{3}{5}。
3. 原来的总量：\frac{3}{5} + \frac{1}{5} = \frac{4}{5}。
4. 但题目中提到的“还剩下 \frac{1}{5}”与计算结果矛盾，说明题目可能存在误导。实际上，如果喝掉 \frac{2}{5} 和 \frac{1}{5}，剩下 \frac{2}{5}，因此题目描述可能有误。
5. 假设题目描述正确，即喝掉 \frac{2}{5} 和 \frac{1}{5} 后剩下 \frac{1}{5}，则原来的总量应为 \frac{2}{5} + \frac{1}{5} + \frac{1}{5} = \frac{4}{5}，但这与“一杯果汁”的常识矛盾。
6. 更合理的解释是题目描述有误，实际应为“喝掉 \frac{2}{5} 和 \frac{1}{5} 后，还剩下 \frac{2}{5}”，此时原来的总量为 1。
7. 因此，题目可能存在错误，但根据常规理解，一杯果汁的总量应为 1。
讲评提示：本题旨在考察学生对分数加法的理解以及对题目描述的批判性思维。教师应引导学生发现题目中的矛盾，并讨论“单位1”的概念。

**q009 答案：** \frac{4}{8}
1. 将等式变形：（ ） = 1 - \frac{1}{8} - \frac{3}{8}。
2. 计算 1 - \frac{1}{8} = \frac{7}{8}。
3. 再计算 \frac{7}{8} - \frac{3}{8} = \frac{4}{8}。
4. 因此，括号里应填 \frac{4}{8}。
5. 由于题目要求“所有可能的解”，而 \frac{4}{8} 是唯一解，因此答案为 \frac{4}{8}。
讲评提示：本题考察同分母分数减法和单位1的理解。教师应强调将 1 化为同分母分数的重要性，并引导学生理解“唯一解”的概念。
